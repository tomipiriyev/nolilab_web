GPS、GSM 与 LoRa：定位跟踪究竟如何工作

GPS 计算位置，蜂窝网络或 LoRa 无线电把位置传送给您。

跟踪器可能知道自己在哪里，而您的手机上显示的却是旧位置。缺失的环节往往是跟踪器与您之间的连接。

要理解其中原因，可以把两项工作分开：确定位置，以及把位置发送出去。前者由 GPS 完成。后者可以由 GSM 等蜂窝技术或 LoRa 无线电链路完成。您选择的连接方式决定了在哪里能收到更新、需要什么设备，以及是否涉及服务套餐。

位置如何到达您的手机

GPS、GSM 和 LoRa 一览

技术在跟踪器中的作用所需条件主要限制
GPS / GNSS根据卫星信号计算坐标能可靠接收卫星信号的接收机不会把坐标发送到您的手机
GSM / 蜂窝通过移动网络发送更新兼容的网络覆盖和有效服务，通常通过 SIM 卡或 eSIM更新取决于网络覆盖和运营商服务
LoRa 点对点通过无线电直接发送小型位置数据包位于无线电覆盖范围内的兼容接收器覆盖距离取决于地形、天线和无线电设置

GPS 负责确定位置

GPS 接收机接收卫星信号，并根据信号的时间计算自身位置。为此它不需要 SIM 卡或移动数据连接，也不会把自己的位置回传给 GPS 卫星。

GPS 是一种卫星导航系统。GNSS 是更宽泛的术语，还包括 Galileo 和 GLONASS 等系统。被称为“GPS 跟踪器”的设备可能同时使用其中多个系统。

信号接收很重要。建筑物、茂密的树木和地形会阻挡信号或降低精度。通信链路正常也无法弥补缺失的位置：跟踪器可能成功送达了消息，却没有最新的位置可发送。GPS.gov 介绍了影响定位精度的因素。

GSM 与蜂窝网络负责发送更新

在典型的蜂窝跟踪器中，GPS 接收机先计算位置，再由蜂窝调制解调器通过移动网络发送到您的应用可以访问的服务。只要跟踪器处于支持的网络覆盖范围内，且您的手机能访问该服务，即使相隔很远也能看到更新。

严格来说，GSM 指的是一种 2G 移动网络标准。现代蜂窝跟踪器可能改用 LTE、LTE-M 或 NB-IoT。这些名称不能互换：设备必须支持您使用地点可用的网络。购买较旧的 GSM 跟踪器之前，请先了解运营商的网络支持计划；2G 和 3G 网络的退网让这一点尤为重要。

蜂窝连接通常需要服务费用，可能是月度订阅、预付费额度，或已包含在购买价格中的服务。应用或云平台还可能另收费用。这些费用支付的是连接和服务，而不是使用 GPS 信号。

LoRa 通过无线电链路发送小数据包

位置更新的数据量很小，因此适合使用专为小消息设计的无线电。LoRa 提供的正是这种无线电链路。在点对点方案中，跟踪器把坐标直接发送给附近的兼容接收器，无需经过蜂窝运营商。

接收器必不可少。普通手机无法自行接收 LoRa 数据包；它需要兼容的硬件把数据传给应用。您还需要待在链路的有效范围内。山丘、建筑物、植被、天线位置和无线电设置都会影响数据包能否送达。

Semtech 将 LoRa 描述为一种低功耗、远距离的无线电技术。但这些特性并不能保证成品跟踪器达到某个特定距离或续航时间。频繁的 GPS 定位和频繁的发送仍然会消耗电量。

LoRa 与 LoRaWAN 是系统中的不同部分

LoRa 是无线电技术；LoRaWAN 是建立在其上的网络协议。LoRaWAN 部署使用网关和网络服务器，而直连点对点链路可以在兼容设备之间运行。产品标注“LoRa”本身并不能说明它是否需要网关、互联网接入或付费网络服务。系统架构请参阅Semtech 的 LoRa 与 LoRaWAN 概述。

连接中断时会发生什么？

设想一只戴着跟踪器的狗跑到了山丘后面。它的 GPS 接收机也许仍能计算出最新位置，但山丘可能阻挡通往您接收器的无线电路径。这时，您的应用中显示的是之前收到的位置，而不能证明狗现在在哪里。

蜂窝跟踪器同样存在定位与传送的分离：在支持的网络覆盖范围之外，它可能知道自己的坐标，却无法发送出去。有些设备会存储位置并稍后上传；请确认具体的跟踪器是否支持这一功能。

查看地图时，除了标记，还要看时间戳。离线使用时，还要确认应用能否显示已保存的地图。在没有互联网的情况下接收坐标与下载地图瓦片是两项不同的功能。

哪种连接方式适合您？

蜂窝方式适合在有网络覆盖的广阔区域内跟踪。它适合行驶范围远超您自有接收器覆盖范围的车辆或资产。请确认具体的网络技术、覆盖范围、更新间隔和持续服务费用。

直连 LoRa 适合可以让接收器保持在覆盖范围内的本地跟踪。它适合野外作业、农场，或在没有移动信号的地方找回设备。请在实际地形中测试链路：开阔的高处路径与山脊后的路线，结果可能截然不同。

如需更详细地比较完整的跟踪器方案，请阅读我们的LoRa 与蜂窝跟踪器对比指南。无论是“GPS”标签还是最大无线电距离数字，都无法告诉您设备能否在您的路线上送达更新。

Loko 如何结合 GPS 与 LoRa

在 Loko 的点对点方案中，Air 单元通过卫星信号获取位置，再通过 LoRa 把坐标发送到 Ground 接收器。接收器负责连接您的手机。这条本地无线电路径不需要蜂窝 SIM 卡，也不需要运营商订阅。

同样的限制依然存在：Air 需要接收卫星信号才能获得最新位置，Ground 需要处于无线电覆盖范围内才能接收。在野外依赖它之前，请规划好接收器的放置位置，并检查整套设备。

如需了解更多，请参阅LoRa GPS 跟踪器指南、Loko 规格和离线跟踪指南。

常见问题

没有 SIM 卡，GPS 能工作吗？

能。只要能接收到可用的卫星信号，GPS 接收机无需 SIM 卡或互联网连接即可计算自身位置。要把这个位置发送给他人，则需要单独的通信链路。

GSM 和 GPS 是一回事吗？

不是。GPS 根据卫星信号计算位置。GSM 是一种 2G 蜂窝通信标准，跟踪器可以用它发送数据。较新的蜂窝跟踪器可能使用其他网络技术。

手机能直接接收 LoRa 吗？

普通智能手机没有内置 LoRa 无线电。直连 LoRa 跟踪方案需要一个兼容的接收器，把位置数据传给手机。

LoRa 跟踪一定不需要订阅吗？

直连的 LoRa 点对点链路不需要蜂窝套餐。但网络服务、应用或云功能可能另行收费，因此请确认完整的产品和服务内容。

LoRa 能让 GPS 更准确吗？

不能。在 GPS 加 LoRa 的跟踪器中，GPS 接收机计算坐标，LoRa 负责传输。无线链路影响的是更新能否送达，而不是这次 GPS 定位的精度。

我能在任何地方跟踪 LoRa 设备吗？

在直连点对点方案中，您需要在无线电覆盖范围内有一个兼容的接收器。通过网关或联网服务实现远程访问，需要额外的基础设施。
