概述

Loko 是一款紧凑型 GPS 无人机跟踪器。两个单位协同工作： Loko Air （机载）获取 GPS 并通过 LoRa 无线电传输； Loko 接地 （基站）接收数据并通过蓝牙将其转发到 Loko 移动应用程序。

洛科航空

GPS + LoRa 发射器 — 安装在飞机上

  • 锂离子电池 200 mAh
  • 13克
  • 电池寿命长达 1 年
  • USB Type-C 充电
洛科地面

LoRa 接收器 + 蓝牙继电器 — 留在地面

  • 18650 锂离子电池（用户提供）
  • 不包含在包装盒中

它是如何运作的

每个唤醒周期，空中单元都会唤醒，获取 GPS 定位，将坐标传输到地面单元，然后休眠直至下一个周期。如果没有可用的卫星定位，则传输最后已知的坐标。 GPS 轨迹日志也写入内部闪存并可通过 USB 下载。

第 1 部分 — 配置 Loko Air

无需安装软件。在基于 Chromium 的浏览器中使用 Web 配置器。

不支持 Firefox 和 Safari — 无 Web Serial API。

1.1 打开配置器

  1. 打开 铬合金 或者 边缘.
  2. 前往 nolilab.com/loko-config-tool/
四个选项卡： 配置 — 设置设备参数。 全球导航卫星系统跟踪 — 从 Air 装置读取 GPS 日志，在地图上可视化，导出 .gpx / .csv。 地面单位 — 配置地面单元。 固件更新 — 刷新最新固件。

1.2 连接

  1. 通过以下方式将 Loko Air 连接到计算机 USB Type-C.
  2. 点击 连接 在配置选项卡上。
  3. 出现提示时授予浏览器串行访问权限 → 选择正确的端口。
如果端口没有出现，请翻转 Type-C 电缆 - 引脚方向很重要。

1.3 设置参数→保存更改

范围描述
transmit_modeP2P 用于直接空中↔地面（标准）。 LoRaWAN 用于网络服务器集成。
frequency868–920 MHz。必须与地面单位完全匹配。
id12 位配对码。必须在空中和地面单位上匹配。
id22 位地面单位标识符。必须匹配地面单位设置。
wake_up_periodAir 设备唤醒的频率。单位：秒/分钟/小时。更短=电池消耗更快。
send_mult每第 N 个唤醒周期发送一次（1 = 每个周期，0 = 禁用）。
save_mult每第 N 个唤醒周期记录 GNSS 跟踪记录（0 = 禁用记录）。
gnss_mode运动概况： 正常 |健身|航空 |气球|固定。默认值：正常。使用航空或气球进行无人机。
tx_powerdBm 中的无线电输出。更高=更远的范围，更多的电池消耗。默认值：8 dBm。
p2p_encryption选修的。 AES-256 的 64 字符十六进制密钥（32 字节）。如果启用，必须与地面单位匹配。

1.4 开机

  1. 断开 USB。
  2. 按住电源按钮直至 LED 呈红色闪烁 → 装置处于活动状态。
红色 LED 常亮 = 传输之间的睡眠模式。正常行为。

第 2 部分 — 配置 Loko 接地

Loko Ground没有内置电池。连接前，拧下四个后部紧固件，插入 18650锂离子电池 （不包括在内），然后重新组装。

2.1 打开配置器→地面单元选项卡

  1. 前往 nolilab.com/loko-config-tool/ 在 Chrome 或 Edge 中。
  2. 单击 地面单位 选项卡。

2.2 连接

  1. 通过 USB 将 Loko 接地连接到计算机。
  2. 点击 连接 → 授予串行访问权限 → 选择端口。

2.3 读取→更新→发送

  1. 点击 读 加载当前设置。
  2. 设置以下参数以匹配空气单元配置。
  3. 点击 发送，然后断开 USB。
范围描述
id22 位标识符。必须与 Air 装置上设置的 id2 匹配。
frequency_hz频率（以 Hz 为单位）（例如 868000000）。必须与 Air 装置完全匹配。
p2p_key仅当 Air 设备上启用加密时。相同的 64 字符十六进制密钥。

2.4 开机与配对

  1. 按住电源按钮直至 LED 亮起 纯蓝色 → 准备配对。
  2. 打开Loko应用程序→授予蓝牙权限→ 设置 → 选择地面单位。
  3. 返回主屏幕。等待 GPS 修复。位置显示在地图上。
支持多个空中单位。点击地图图钉即可查看设备详细信息。

警告

防水的

不防水。远离液体。务必盖住 Air 设备上的 USB 端口。

火

请勿暴露于明火或极热环境中。

温度

仅在 0 °C – 40 °C 范围内运行。

电压

仅以 5V 充电。更高的电压会损坏设备。

射频

请勿用金属封装。远离强电磁源。

天线

安装天线朝上，离地面尽可能高。

眼睛安全

使天线尖端远离儿童和动物的眼睛。
