关于 Loko 应用程序

Loko 导航应用程序是 Loko GPS 跟踪器系统的配套应用程序。它通过蓝牙连接到 Loko 地面站，并在地图上显示所有配对空中装置的实时 GPS 位置 - 所有这些都无需任何互联网连接。该应用程序仅在您的设备上存储跟踪历史记录；没有数据发送到任何服务器。

离线地图 预先下载地图图块，以便在没有互联网或移动覆盖的区域使用。在偏远的田野、森林和山区工作。
实时位置更新 当更新从地面站到达时，查看每个跟踪的 Loko 空中装置的实时 GPS 位置。
多跟踪器支持 在单个地图视图上同时跟踪最多 30 个空军单位，每个单位都分配有唯一的颜色和标签。
地理围栏警报 在任何位置周围设置虚拟边界，并在被跟踪的设备进入或离开该区域时收到警报。
追踪历史记录 查看任何空军部队的完整路线，并使用时间戳重播过去的跟踪会话。
没有订阅，没有帐户 所有功能都是免费的，并且完全离线工作。无需云帐户或月费。

桌面配置工具

Loko 桌面应用程序通过 USB 连接到您的空中或地面装置，并允许您设置 LoRa 无线电参数、设备 ID、GPS 更新间隔和跟踪记录周期。它还显示实时串行输出以进行诊断。

macOS、Windows 和 Linux 在 macOS 10.14+、Windows 10/11 和 Linux（64 位）上运行。无需订阅或互联网连接。
需要 USB 连接 使用 USB-C 数据线（而非专用充电线）。与空中装置和地面装置固件兼容。
基于浏览器的替代方案 使用 Loko在线配置工具 在 Chrome 中 — 无需安装。

常见问题解答

该应用程序是免费的吗？ 是的。 Loko 应用程序可免费下载，无需应用内购买或订阅费。所有功能均包含在内。
该应用程序需要互联网连接吗？ 不会。下载地图图块后，该应用程序将完全离线运行。 GPS 跟踪通过 LoRa P2P 无线电进行 - 不需要蜂窝或 Wi-Fi 网络。
该应用程序会收集我的位置数据吗？ 不会。Loko 具有严格的零数据收集政策。所有跟踪数据都保留在您的设备上。请参阅 隐私政策 了解详情。
支持哪些 Android 版本？ Loko 应用程序支持 Android 8.0 (Oreo) 及更高版本。它还可以在 LineageOS 15.1 及更高版本上运行，适合喜欢开源 Android 版本的用户。
我可以在没有 Loko 地面站的情况下使用该应用程序吗？ 该应用程序需要通过蓝牙连接的 Loko 地面站来接收来自空中装置的实时 GPS 数据。地面站包含在 Loko 入门套件中或单独提供。
