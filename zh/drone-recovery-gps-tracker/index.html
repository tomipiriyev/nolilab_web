无人机恢复 GPS 跟踪器

一款轻型备用追踪器，用于在坠机或信号丢失后寻找丢失的无人机。

丢失无人机通常发生在最糟糕的时刻：电池电量低、视频链路损坏、着陆困难、高草丛、树木或飞行区域附近没有蜂窝网络覆盖。

Loko为无人机飞行员提供了独立的恢复通道。跟踪器通过 LoRa 无线电发送 GPS 位置，即使在主控制链路或视频系统出现故障时也能帮助您定位飞机。

为什么无人机需要独立的恢复跟踪

无人机的主要遥测链路不是恢复系统。它可能因距离、天线方向、电池断开、碰撞损坏或地形障碍而发生故障。

独立的跟踪器可以降低一次故障同时取消所有恢复选项的可能性。

LoRa 为无人机飞行员提供帮助

LoRa 非常适合以低功耗长距离发送小型 GPS 数据包。无人机回收跟踪器不需要视频带宽；它只需要可靠的位置更新。

开阔的场地和清晰的视线可提供最佳性能。树木、山丘和碳框架会缩小覆盖范围，因此安装位置和天线方向很重要。

最佳无人机用例

Loko 对于 FPV 飞机、远程无人机、测绘飞机、研究无人机以及昂贵的建筑非常有用，在这些建筑中，恢复比增加尽可能小的重量更重要。

对于蜂窝跟踪器可能没有服务的农村发射场来说，它尤其有价值。

常问问题

Loko可以用在无人机上吗？

是的，当尺寸、重量、安装和天线位置适合飞机时。

Loko 能否取代飞控遥测？

不。它最好用作独立的备份恢复跟踪器。

无人机跟踪器需要蜂窝服务吗？

Loko 没有。它使用 LoRa 无线电接收器。

LoRa 适合无人机回收吗？

是的。 LoRa 专为长无线电链路上的小型低功耗数据包而设计，非常适合 GPS 恢复数据。

Loko GPS 跟踪器使用 GPS 和 LoRa 无线电进行本地跟踪，无需 SIM 卡、互联网或按月订阅。
