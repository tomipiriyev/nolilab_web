不带手机服务的 GPS 追踪器

在手机没有信号的地方跟踪人员、宠物、无人机和设备。

GPS 跟踪器可以在没有蜂窝服务的情况下工作，但前提是它有一种不依赖于 LTE、GSM 或移动数据的发送位置的方式。 GPS 卫星提供坐标。当塔消失时，大多数追踪器都会失去通信链路。

Loko 通过 LoRa 无线电解决了这个问题。跟踪器从卫星接收 GPS 位置，并将小型位置数据包直接发送到本地接收器，因此可以在农场、小径、无人机田地、农村土地和远程工作地点继续进行跟踪。

为什么大多数 GPS 跟踪器在没有蜂窝服务的情况下会失败

许多“GPS 跟踪器”实际上是 GPS+ 蜂窝设备。他们可以离线计算位置，但他们通过移动网络发送该位置。当跟踪器超出覆盖范围时，应用程序将停止接收实时更新。

这就是为什么人们经常看到跟踪器的最后已知位置，但看不到它在森林、山谷、偏远农场或大型乡村地产中的当前位置。

Loko 如何在没有手机信号塔的情况下进行跟踪

Loko 使用两种独立的技术。 GPS/GNSS 从卫星接收位置。 LoRa P2P 无线电将该位置从空中跟踪器本地发送到地面接收器。接收器通过蓝牙连接到您的手机。

这意味着本地跟踪不需要 SIM 卡、LTE 调制解调器、Wi-Fi 和云服务器。实际范围取决于视线、天线位置、地形和植被。

无蜂窝服务跟踪的最佳用例

Reddit 上关于乡村追踪、远足、宠物和 GPS 应用程序的讨论反复表明了同样的需求：当手机应用程序或蜂窝跟踪器无法连接时实时显示本地位置。

Loko 适合追踪农村土地上的狗、坠机后的无人机、农场设备、步道合作伙伴、现场团队、野生动物项目以及偏远房产周围的资产。

常问问题

GPS 追踪器可以在没有手机服务的情况下工作吗？

是的。 GPS 通过卫星工作。跟踪器还需要非蜂窝链路（例如 LoRa 无线电）将位置发送到附近的接收器。

Loko需要SIM卡吗？

不需要。Loko P2P 跟踪使用 LoRa 无线电而不是 LTE 或 GS​​M，因此没有 SIM 卡或每月的蜂窝套餐。

什么追踪器适用于没有信号的农村地区？

对于本地跟踪，LoRa GPS 跟踪器可以在蜂窝跟踪器停止更新的地方工作，因为它不依赖于移动塔。

Loko 是卫星跟踪器吗？

不会。Loko 使用 GPS 卫星进行定位，使用 LoRa 无线电进行本地通信。它不是全球卫星消息传递设备。

Loko GPS 跟踪器使用 GPS 和 LoRa 无线电进行本地跟踪，无需手机服务、SIM 卡或按月订阅。
