无蜂窝信号 GPS 追踪器

在手机无信号的地方追踪人员、宠物、无人机和设备。

GPS 追踪器可以在没有蜂窝网络时定位，但前提是它有不依赖 LTE、GSM 或移动数据的位置发送方式。GPS 卫星提供坐标，多数追踪器在没有基站时丢失的是通信链路。

Loko 用 LoRa 无线电解决这个问题。追踪器从卫星接收 GPS 位置，并把小型位置数据包直接发送到本地接收器，因此在农场、山路、无人机场地、乡村土地和偏远工地也能继续追踪。

为什么多数 GPS 追踪器离开蜂窝网络就失效

许多“GPS 追踪器”其实是 GPS 加蜂窝通信设备。它们可以离线计算位置，但通过移动网络发送位置。一旦离开覆盖区，应用就停止接收实时更新。

这就是为什么在森林、山谷、偏远农场或大型乡村物业中，人们常常只能看到最后已知位置，而不是当前位置。

Loko 如何不靠蜂窝基站追踪

Loko 使用两种独立技术。GPS/GNSS 从卫星接收位置，LoRa P2P 无线电把位置从 Air 追踪器本地发送到 Ground 接收器，接收器再通过 Bluetooth 连接手机。

这意味着本地追踪不需要 SIM 卡、LTE 调制解调器、Wi-Fi 或云服务器。实际距离取决于视距、天线位置、地形和植被。

无蜂窝追踪的最佳用途

Reddit 上关于农村追踪、徒步、宠物和 GPS 应用的讨论反复出现同一个需求：当手机应用或蜂窝追踪器无法连接时，仍需要本地实时位置。

Loko 适合追踪乡村土地上的狗、坠落后的无人机、农场设备、徒步伙伴、野外团队、野生动物项目以及偏远物业中的资产。

什么时候需要卫星设备

如果你需要把位置发送给几百或几千公里外的人，而且附近没有本地接收器，卫星通信设备才是正确类别。

Loko 最适合本地找回和本地态势感知：追踪者与追踪器处于同一大区域，可以直接接收 LoRa 数据包。

常见问题

GPS 追踪器可以没有蜂窝网络也工作吗？

可以。GPS 通过卫星工作。追踪器还需要非蜂窝链路，例如 LoRa 无线电，把位置发送到附近接收器。

Loko 需要 SIM 卡吗？

不需要。Loko P2P 追踪使用 LoRa 无线电，而不是 LTE 或 GSM，因此没有 SIM 卡或每月蜂窝套餐。

无信号农村地区用什么追踪器？

对于本地追踪，LoRa GPS 追踪器可以在蜂窝追踪器停止更新的地方工作，因为它不依赖移动基站。

Loko 是卫星追踪器吗？

不是。Loko 使用 GPS 卫星定位，并用 LoRa 无线电进行本地通信。它不是全球卫星消息设备。

Loko GPS Tracker 使用 GPS 加 LoRa 无线电进行本地追踪，无需蜂窝网络、SIM 卡或月费订阅。
