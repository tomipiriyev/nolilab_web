适用于偏远地区的 GPS 跟踪器

对正常网络消失的地方进行独立于基础设施的跟踪。

偏远地区跟踪有一个简单的问题：许多 GPS 跟踪器依赖于偏远地区缺乏的确切基础设施。

Loko 避免了这种依赖性。该跟踪器接收卫星位置并使用 LoRa 无线电在本地传输，因此它可以在正常的 GSM 和互联网覆盖范围之外工作。

独立于基础设施的跟踪

独立于基础设施的跟踪意味着跟踪器不依赖移动塔、Wi-Fi 路由器或云服务器来进行本地位置更新。

Loko 的设计围绕这一原则：GPS 用于定位，LoRa 用于 comm 通信，蓝牙用于电话连接。

Loko 适合的偏远地区

良好的用例包括农村财产、森林、山区、无人机恢复区、狩猎区、农场、救援训练场地和远程野外工作。

开阔的地形和视线提高了 LoRa 的性能。丘陵、茂密的森林、建筑物和低矮的天线会缩小覆盖范围。

常问问题

GPS追踪可以在偏远地区工作吗？

是的，如果跟踪器具有天空可见性和不依赖于本地手机信号塔的 comm 通信方法。

Loko 使用 GSM 吗？

不会。Loko 使用 LoRa P2P 无线电进行本地跟踪。

独立于基础设施的跟踪意味着什么？

这意味着本地跟踪不需要公共网络，例如蜂窝塔、Wi-Fi 或云中继。

Loko 适合偏远农场和小径吗？

是的，当部署在实际的 LoRa 无线电范围内时。

Loko GPS 跟踪器使用 GPS 和 LoRa 无线电进行本地跟踪，无需 SIM 卡、互联网或按月订阅。
