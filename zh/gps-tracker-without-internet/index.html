无需互联网的 GPS 追踪器

即使手机没有数据信号、云端追踪器停止更新，也能追踪位置。

GPS 追踪器无需互联网即可计算位置，因为它直接接收导航卫星的信号。 不同之处在于追踪器如何将位置信息发送给您：云端追踪器使用蜂窝数据，而离线追踪器使用 LoRa 无线电等本地连接。

Loko 专为离线追踪而设计。追踪器接收卫星定位信息，并通过 LoRa 无线电将其发送到您的手持接收器，因此即使没有 Wi-Fi、移动数据或云端连接，也能持续更新位置。

离线 GPS 追踪的含义

离线 GPS 追踪意味着设备无需依赖互联网即可计算并共享位置。GPS 提供坐标，本地无线电链路则将这些坐标传送给执行追踪的人。

这不同于离线地图。离线地图可帮助手机在没有移动数据时显示地形，而 Loko 补上了缺失的一环：通过无线电链路将被追踪对象的位置传回给你。

无需互联网的 GPS 追踪器最适合在哪些地方使用

离线追踪适用于森林、农场、山间小径、无人机飞行场、乡村地产、建筑工地、搜索区域，以及蜂窝网络信号较弱的任何地点。蓝牙标签在这些地方也会失去作用，因为 AirTag 只有在附近的 iPhone 帮助转发时才会更新；因此当地的养犬者通常需要真正的 GPS 犬用 AirTag 替代方案.

实际范围取决于地形、天线位置和视距条件。开阔地形下效果最佳。山丘、建筑物、茂密植被以及较低的天线位置都会缩短范围。

需要了解的局限性

Loko 不是卫星通信设备，无法自行将你的位置发送给远在世界另一端的人。它是一套本地远距离无线电追踪系统。

如果需要在远超本地无线电范围的地方进行紧急通信，卫星通信器才是合适的类别；了解 Garmin inReach 的本地无线电替代方案 有何不同。对于无需互联网的本地寻回和资产追踪，Loko 更为合适。

常见问题

GPS 能在没有互联网的情况下工作吗？

能。GPS 卫星无需互联网即可工作。只有依赖云端数据传输的应用或追踪器才需要互联网。

如果我的手机没有信号，Loko 还能显示位置吗？

能。Loko Ground 通过 LoRa 接收追踪器信号，并通过 Bluetooth 连接到您的手机。

Loko 需要 Wi-Fi 吗？

不需要。Loko P2P 追踪无需 Wi-Fi。

这和卫星追踪器一样吗？

不一样。Loko 是使用本地 LoRa 无线电的 GPS 追踪器，并非卫星通信设备。

Loko GPS 追踪器结合使用 GPS 和 LoRa 无线电，无需 SIM 卡、互联网或月度订阅即可进行本地追踪。
