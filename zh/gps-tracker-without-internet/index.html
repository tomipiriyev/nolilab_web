GPS 追踪器（无需互联网）

跟踪手机没有数据信号且云跟踪器停止更新的位置。

GPS 位置不需要互联网接入。 GPS 卫星在全球范围内广播定位信号。许多跟踪器仅使用互联网将位置转发回应用程序。

Loko 专为离线跟踪而设计。跟踪器接收卫星位置并通过 LoRa 无线电将其发送到您的手持接收器，因此位置更新可以在没有 Wi-Fi、没有移动数据和没有云连接的地方继续进行。

离线 GPS 跟踪意味着什么

离线 GPS 跟踪意味着设备可以在不依赖互联网的情况下计算和共享位置。 GPS 提供坐标。本地无线电链路将这些坐标传送给进行跟踪的人。

这与离线地图不同。离线地图可帮助您的手机显示地形，无需移动数据。 Loko 添加了缺失的部分：从被跟踪对象返回给您的无线电链路。

在没有互联网的情况下使用 GPS 跟踪器的最佳地点

离线跟踪适用于森林、农场、山路、无人机飞行场、农村地产、建筑工地、搜索区域以及任何蜂窝服务薄弱的地方。

实际范围取决于地形、天线位置和视线。开阔的地形表现最好。山丘、建筑物、茂密的植被和较低的天线位置会缩小覆盖范围。

需要理解的局限性

Loko 不是卫星信使，它本身不会将您的位置发送给世界各地的某人。它是一个本地远程无线电跟踪系统。

对于远远超出本地无线电范围的紧急 communication，卫星 communicator 是正确的类别。对于无需互联网的本地恢复和资产跟踪，Loko 更适合。

常问问题

GPS 可以在没有网络的情况下工作吗？

是的。 GPS 卫星无需互联网即可工作。只有依赖云数据传输的应用程序或跟踪器才需要互联网。

如果我的手机没有信号，Loko 可以显示位置吗？

是的。 Loko Ground 通过 LoRa 接收跟踪器并通过蓝牙连接到您的手机。

Loko 需要 Wi-Fi 吗？

不需要。Loko P2P 跟踪不需要 Wi-Fi。

这和卫星跟踪器一样吗？

不。Loko 是本地 LoRa 无线电 GPS 跟踪器，而不是卫星消息传递设备。

Loko GPS 跟踪器使用 GPS 和 LoRa 无线电进行本地跟踪，无需 SIM 卡、互联网或按月订阅。
