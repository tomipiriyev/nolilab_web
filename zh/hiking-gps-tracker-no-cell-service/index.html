在没有手机服务的情况下徒步 GPS 追踪器

离线本地跟踪步道、营地和远程户外路线。

许多徒步旅行地区的移动服务不可靠。手机仍然可以使用 GPS，但如果没有网络，共享位置或查找移动的人员或资产就会变得困难。

Loko 使用 GPS 加上 LoRa 无线电进行本地离线跟踪。当团体、向导、训练员或现场团队想要在不依赖蜂窝网络覆盖的情况下跟踪附近的人、狗或装备时，它非常有用。

Loko 在小径上的优势

Loko 可以帮助在实际无线电范围内跟踪狗、背包、自行车、车辆或团体成员。它在营地、步道起点、搜索区和乡村路线周围非常有用。

由于该系统不需要移动数据，因此在手机失去信号后仍可以继续工作。

Loko 不是什么

Loko 不能替代卫星紧急信标或卫星信使。它不会自动通知地球上任何地方的救援服务。

如需紧急求救，请使用专用的卫星安全装置。对于没有小区覆盖的本地跟踪，Loko 扮演了不同的角色。

户外期望范围

开阔的山脊线和清晰的地形提供了最强的无线电性能。深谷、潮湿的森林、岩石和身体阻挡会减少射程。

对于徒步旅行使用，请将接收器放在天线可见度良好的地方并测试您的设置，然后再在偏远地区使用它。

常问问题

GPS 可以在没有手机服务的情况下进行徒步旅行吗？

是的。 GPS 接收无需蜂窝服务即可工作。

Loko 可以在没有网络的情况下追踪其他徒步旅行者吗？

是的，如果跟踪器和接收器位于实际的 LoRa 无线电范围内。

Loko 是 SOS 设备吗？

不。它是本地 GPS 跟踪系统，而不是紧急卫星信使。

Loko 是否需要每月远足计划？

不需要。Loko 不使用蜂窝网络订阅。

Loko GPS 跟踪器使用 GPS 和 LoRa 无线电进行本地跟踪，无需 SIM 卡、互联网或按月订阅。
