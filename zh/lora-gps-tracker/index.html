技术

LoRa 是什么？它为何能让 GPS 追踪器更出色？

LoRa 是 Long Range（远距离）的缩写。它是 Semtech 开发的一种无线调制技术，采用啁啾扩频（CSS），能将小数据包传输到 Wi-Fi、Bluetooth 或 Zigbee 无法企及的距离。

其关键物理原理是：LoRa 以数据速率换取通信距离和穿透能力。它传输数据的速度较慢，但距离非常远、可靠性极高，即使隔着墙壁、树木和地形也能稳定传输。对于 GPS 追踪而言，位置更新只是每隔几秒到几分钟发送一次的小数据包，因此非常适合。

为何 LoRa 在 GPS 追踪方面优于其他无线协议

通信距离

公里级通信距离

在无遮挡视距条件下，Loko 的 LoRa 链路最远可达 20 km。Wi-Fi 和 Bluetooth 等短距离技术面向的是不同的覆盖范围和数据速率需求。

功耗

超低能耗

LoRa 无线电在两次传输之间耗能极低。配合较长的更新间隔，Loko 的续航最长可达一年；更频繁的 GPS 定位和传输会缩短续航时间。

穿透能力

可穿越障碍物

LoRa 使用的 Sub-GHz 频率（欧盟为 868 MHz，美国为 915 MHz）穿透植被、建筑材料和起伏较缓地形的能力，远胜于 2.4 GHz Wi-Fi 或使用高频段的蜂窝网络。

独立性

无需网络基础设施

LoRa P2P 可让设备之间直接通信。整个追踪链路在任何环节都不需要蜂窝基站、网关、服务器或互联网连接。

成本

零运营成本

LoRa 使用免许可的 ISM 无线电频段。无需支付通信时长费或数据费，也不需要运营商。硬件是唯一的成本。

可靠性

无单点故障

LoRa P2P 链路由两部分组成：追踪器和接收器。没有云端、运营商网络或服务器会因离线而中断连接。

定位精度

GPS 精度：与 LoRa 有什么关系（毫无关系）

一个常见误解是：LoRa 无线电对 GPS 定位精度完全没有影响。这两个系统彼此完全独立。

GPS 定位精度 完全取决于 Loko Air 中的 GNSS 接收器。Loko 可同时支持四大全球卫星导航系统：

  • GPS （美国）— 31 颗卫星
  • GLONASS （俄罗斯）— 24 颗卫星
  • Galileo （欧盟）— 30 颗卫星
  • BeiDou （中国）— 35+ 颗卫星

同时使用这四大卫星导航系统，可让 Loko 更快地获取位置（首次定位时间），并提高定位精度，尤其是在峡谷地形或茂密林冠等仅能看到部分卫星的复杂环境中。

开阔天空下的典型定位精度： 2–5 米 CEP （圆概率误差）。这与所有支持多星座的消费级 GNSS 设备相同，并且与用于传输位置信息的无线电技术无关。

LoRa 的作用 仅限于传输：它获取 GPS 坐标，并将其准确无误地远距离传送到接收器。LoRa 使用前向纠错（编码率参数），确保即使在无线电干扰严重的环境中，位置数据也能完整送达。

常见问题

关于远距离 LoRa GPS 追踪器的常见问题

LoRa GPS 追踪器的通信距离有多远？

在视线无遮挡的开阔地形中，Loko 的通信距离可达 20 km。城市建筑、森林、山丘、较低的天线位置和无线电设置都会缩短实际通信距离。请参阅 无线电视距指南 ，了解影响覆盖范围的因素。

什么是 LoRa GPS 追踪器？

LoRa GPS 追踪器将 GNSS 接收器（通过卫星确定位置）与 LoRa 无线电发射器（通过无线方式将位置信息传输到远距离）结合在一起。与蜂窝 GPS 追踪器不同，LoRa GPS 追踪器不需要 SIM 卡或移动网络，而是通过无线电与附近的接收器直接通信。

LoRa GPS 追踪器需要订阅吗？

Loko 无需任何订阅。由于它使用 LoRa 无线电而非蜂窝网络，因此没有 SIM 卡成本、流量套餐费用或月费。硬件只需购买一次，即可无限期追踪。这是 LoRa 相比蜂窝追踪方案的主要优势之一。

用于 GPS 追踪时，LoRa P2P 与 LoRaWAN 有什么区别？

LoRa P2P（点对点）是设备之间的直接通信，追踪器直接与您的接收器通信，中间无需任何基础设施。LoRaWAN 使用网关和网络服务器，在已部署网关的区域能提供更广的覆盖范围，但必须有相应的基础设施。Loko 使用 LoRa P2P，因此只需两个设备，无需其他设置，便可在任何地方工作。完整比较请参阅 LoRaWAN 页面.

用于 GPS 追踪时，LoRa 比蜂窝网络更好吗？

这取决于具体应用。LoRa 适合在没有蜂窝网络覆盖或不想为每台设备支付数据费时进行本地追踪。若被追踪物有网络覆盖且附近没有接收器，蜂窝网络则适合远程云端访问。

LoRa GPS 追踪器的精度如何？

Loko 中的 GPS 精度完全取决于 GNSS 接收器，而非 LoRa 无线电。Loko 同时支持 GPS、GLONASS、Galileo 和 BeiDou，在开阔天空下可实现约 2–5 米 CEP 的定位精度，与任何多星座 GNSS 设备相同。LoRa 无线电在传输该位置时不会引入任何定位误差。

哪些因素会影响 LoRa GPS 追踪器的通信距离？

主要影响因素包括接收器高度、地形、扩频因子、发射功率和天线质量。在路径无遮挡的开阔地形中，Loko 最远可达 20 km。

LoRa GPS 追踪器能否同时追踪多个设备？

可以。Loko 支持将多个 Loko Air 追踪器同时连接到一个 Loko Ground 接收器。所有追踪位置都会实时显示在同一张离线地图上，方便使用单个设备追踪畜群、人员团队或车队。

我可以将 LoRa 追踪器用作狗或宠物追踪器吗？

可以。对于活动范围超出 Bluetooth 或蜂窝网络覆盖的动物，Loko 可用作 LoRa 狗用追踪器或 LoRa 宠物追踪器。与 AirTag 不同，LoRa 追踪器无需 SIM 卡或月费，即可从最远 20 km 外实时报告 GPS 位置，因此适合在无蜂窝网络覆盖的地区追踪猎犬、工作犬和自由活动的宠物。
