离网 GPS 跟踪器

GPS 跟踪手机信号塔、Wi-Fi 和云覆盖范围之外的地方。

当手机失去服务时，离网 GPS 跟踪器应该继续工作。这意味着它不能依赖 GSM、LTE、Wi-Fi 或云服务器来中继每个位置更新。

Loko 是围绕离线操作构建的。它从卫星接收 GPS 位置，并通过 LoRa 无线电将小型位置数据包发送到本地接收器。

是什么让跟踪器脱离电网

当跟踪器能够在不依赖公共通信基础设施的情况下计算和传输有用的位置数据时，它就真正脱离了电网。

GPS提供全球定位，但通信通道是最难的部分。 Loko 解决了 LoRa P2P 无线电的本地通信问题。

离网跟踪的价值所在

离网跟踪对于农场、步道、营地、无人机场地、实地研究区域、建筑工地和农村财产非常有用。

当订阅跟踪器既昂贵又不可靠（因为蜂窝覆盖范围很小或没有）时，它就尤其有价值。

当离网 LoRa 不够时

如果您需要数千公里之外的全球位置更新，则需要蜂窝或卫星基础设施。

当人员跟踪与被跟踪对象处于同一广阔区域并且可以使用本地接收器时，Loko 最强。

常问问题

什么是离网 GPS 跟踪器？

它是一款设计为无需互联网、Wi-Fi 或蜂窝网络覆盖即可运行的跟踪器。

Loko 需要手机服务吗？

不会。Loko P2P 跟踪使用 LoRa 无线电而不是蜂窝数据。

离网 GPS 与卫星信息相同吗？

不需要。GPS 定位基于卫星，但通信可以使用 LoRa、蜂窝、Wi-Fi 或卫星网络。

谁需要离网追踪器？

无人机飞行员、农民、徒步旅行者、现场研究人员以及任何在偏远地区跟踪资产的人。

Loko GPS 跟踪器使用 GPS 和 LoRa 无线电进行本地跟踪，无需 SIM 卡、互联网或按月订阅。
