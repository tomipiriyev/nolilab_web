AirTag 与 LoRa GPS 追踪器：诚实的比较

两种截然不同的技术以截然不同的方式解决同一问题

Apple AirTag 是世界上最受欢迎的物品追踪器之一。 29 美元且免月费，这看起来是一笔无与伦比的交易。但 AirTag 不是 GPS 跟踪器——这种区别在现实世界中非常重要。

AirTag 是一个蓝牙信标，依赖其他人的 iPhone 来工作。 在城市里，这通常很好。在远足小径、偏远农场或 iPhone 人流较少的任何地方，AirTag 可能会完全失败。

LoRa GPS 跟踪器（如 Loko）的工作方式不同：它们使用真正的 GPS 卫星进行定位，并使用专用的远程无线电链路进行传输。没有众包，不依赖其他设备，没有盲区。

AirTag 的工作原理及其在偏远地区失败的原因

AirTag 包含低功耗蓝牙 (BLE) 无线电和超宽带 (UWB) 芯片，用于精确的附近测向。它不包含 GPS。以下是它实际获取位置的方式：

  1. AirTag 广播旋转蓝牙信号
  2. 附近任何运行 iOS 14.5+ 的 iPhone 都会默默检测到该信号
  3. 该 iPhone 使用自己的 GPS 来记录检测到 AirTag 的位置
  4. 该位置被匿名上传到 Apple 的服务器
  5. 您可以在“查找我的”应用程序中查看最后检测到的位置

这种架构（称为众包定位）在 iPhone 密度高的地方表现出色。在繁忙的机场、购物中心或城市街区，iPhone 随处可见，并且您的 AirTag 位置会经常更新。

当你离开文明的那一刻，致命的缺陷就出现了。在森林、山谷、乡村田野或任何没有定期 iPhone 人流量的区域，您的 AirTag 可能会持续数小时或数天而不被检测到。如果您的狗跑进了偏远的森林，您的 AirTag 将显示它最后检测到的位置 - 这可能是您的车道。

AirTag 也仅适用于 Apple 设备。 Android 用户根本无法使用 AirTag 或“查找我的”网络。该众包网络仅包括 iPhone——三星、谷歌 Pixel 和其他 Android 用户不参与。

LoRa GPS 的工作原理 — 直接、独立、无处不在

像 Loko 这样的 LoRa GPS 跟踪器使用完全不同的架构，不需要基础设施，也不需要其他人的设备。

信号链是完全独立的：

  1. Loko Air 跟踪器直接从绕地球运行的卫星接收 GPS 信号
  2. 它计算自己的精确坐标（纬度、经度、海拔）
  3. 它通过 LoRa 无线电将这些坐标直接传输到您的 Loko Ground接收器
  4. Loko Ground通过蓝牙将数据发送到您的手机
  5. Loko 应用程序在离线地图上显示您的资产的位置

这条链条中的任何一个环节都不涉及互联网。没有云服务器，没有SIM卡，没有蜂窝网络，也不依赖别人的手机。 Loko Air 和 Loko Ground 之间的直接 LoRa 无线电链路工作可达 开阔地形中的 20km.

这意味着无论您是在伦敦市中心还是在偏远的喜马拉雅山小道上，Loko 的工作原理都是相同的。唯一的要求是 GPS 卫星是可见的——它们确实是可见的，基本上在地球表面的任何地方。

当 AirTag 获胜时 vs 当 Loko 获胜时

AirTag 在以下情况下效果更好：

  • 您位于 iPhone 流量密集的市区
  • 您想要最便宜的硬件（29 美元）
  • 你已经深入苹果生态系统了
  • 您需要超精准近距离测向（<10m）
  • 您正在主要机场追踪行李
  • 长期被动跟踪是可以接受的（非实时）

Loko LoRa GPS 在以下情况下更好：

  • 您在偏远地区、森林或农场
  • 您需要实时位置更新，而不是众包历史记录
  • 您使用 Android 手机或 iOS 和 Android 混合手机
  • 您需要实际的 20km 直接无线电范围
  • 您正在户外追踪宠物、牲畜或无人机
  • 您需要跟踪器与周围零人一起工作

诚实的 summary：AirTag 是一个巧妙的蓝牙信标，装扮成跟踪器。对于 iPhone 随处可见的城市用例，它的效果出奇的好。对于任何户外或远程用例，它根本不适合该任务。

Loko 是真正的 GPS 跟踪器。它知道自己的确切坐标，独立于任何其他设备，并通过 20km 无线电链路将这些坐标直接传输给您。没有众包，没有云，没有妥协。

AirTag 与 LoRa GPS 跟踪器：常见问题解答

AirTag 和 LoRa GPS 跟踪器之间的主要区别是什么？

AirTag 使用蓝牙和 Apple 的众包“查找我的”网络 - 它依靠附近的 iPhone 来转发其位置。像 Loko 这样的 LoRa GPS 跟踪器使用实际的 GPS 卫星和专用的远程无线电链路。 Loko适用于零电话或附近人员的偏远地区； AirTag 没有。

AirTag 可以在偏远地区或森林中使用吗？

不会。AirTag 依赖于在标签的蓝牙范围 (~10m) 内行走的其他 iPhone 用户。在偏远的森林、山间小道或乡村农场，周围可能几英里内都没有人。在这些环境中，AirTag 实际上停止工作。 Loko GPS 跟踪器可在 GPS 卫星可见的任何地方工作 — 无需人员。

AirTag 有 GPS 吗？

不可以。AirTag 不包含 GPS 芯片。它使用低功耗蓝牙与附近的 iPhone 进行 comm 连接，然后 iPhone 使用自己的 GPS 报告大致位置。这与直接根据卫星信号计算自身坐标的真正的 GPS 跟踪器有根本的不同。

AirTag 与 Loko 的有效范围是多少？

AirTag 使用超宽带的直接精确查找范围约为 30-100 米。其众包的“Find My”范围理论上是无限的，但只有当其他 iPhone 碰巧经过时才有效。 Loko 在开阔地形中的直接无线电范围高达 20km，完全独立于其他人的设备。

哪一个更适合追踪宠物、行李或户外装备？

这取决于你在哪里。 AirTag 在密集的城市环境中表现出色，因为附近总是有 iPhone 用户。对于偏远地区的宠物、远足装备或任何可能最终出现在人流量少的地方的物品，像 Loko 这样的 LoRa GPS 跟踪器要可靠得多，因为它不依赖于其他人的设备。

AirTag 是一个很好的蓝牙信标。 Loko 是真正的 GPS 跟踪器。如果您需要现实世界中的可靠位置（户外、远程、不依赖其他人的手机），那么有一个明确的选择。
