将 Loko 连接到 LoRaWAN 网络

将您的 Loko Air 追踪器与 The Things Network（TTN）配对，只需四个简单步骤，即可开始在应用中接收实时位置。

约 10 分钟 · 新手友好

Loko 通过 LoRaWAN（一种远距离、低功耗的无线电网络）接收追踪器的位置。为了将这些无线电消息传送到您的手机，应用会连接到 The Things Network（TTN）——一个免费的全球 LoRaWAN 社区网络。

设置在两个地方进行：首先在 TTN 控制台创建一个应用并注册您的设备，然后将两项凭据粘贴到 Loko 应用中。以下是您需要的一切。

您需要准备

  • ▸
    一个免费的 TTN 账户如果还没有，请在 thethingsnetwork.org 注册。
  • ▸
    您的 Loko Air 设备信息DevEUI / JoinEUI / 密钥——在注册设备时由您自行设置。
  • ▸
    已安装 Loko 应用在您用于追踪设备的手机上。
🎯
完成后，您将获得两个值——一个 Application ID 和一个 API Key——这是应用上线所需的全部内容。
1

在 TTN 中创建应用

登录 TTN 控制台，打开 Applications 部分并点击 + Add application。为其设置一个 ID 和名称，然后点击 Create application。

📝
记下您的 Application ID。应用会用到它。在上面的示例中是 demolokoappid。该 ID 必须为小写，且之后无法更改。
2

注册您的 Loko Air 设备

在左侧边栏打开 End devices，然后点击 Register end device。

在注册界面选择 “Enter end device specifics manually”，然后填写您 Loko Air 的设备信息（频率计划、LoRaWAN 版本，以及 JoinEUI / DevEUI 等配置信息）。

📡
为您所在区域选择频率计划（例如 Europe 863–870 MHz），并将 LoRaWAN 版本与您的 Loko Air 匹配。为您拥有的每个追踪器重复此步骤。
3

创建 API 密钥

回到边栏，打开 API keys 并点击 + Add API key。授予其读取应用流量的权限，然后保存。

🔑
请立即复制 API 密钥。TTN 仅在创建后显示一次完整密钥。请妥善保存——如果丢失，您将不得不重新生成一个。
✓

可选——使用 MQTT Explorer 测试

在将凭据输入 Loko 之前，您可以使用任何开源 MQTT 客户端（例如 MQTT Explorer）验证其是否有效。它直接连接到 TTN 的 MQTT 服务器并显示原始上行消息，可快速确认一切设置正确。

🔌
使用以下设置：Protocol mqtt://、Host eu1.cloud.thethings.network（与您的区域匹配）、Port 1883。Username 是您的 Application ID 加上 @ttn（与应用中的规则相同！），Password 是您的 API 密钥。点击 Connect——如果连接成功并看到主题出现，说明您的凭据没有问题。
4

从 Loko 应用连接

打开 Loko 应用，进入 LoRaWAN (TTN) 面板并输入您的凭据。使用 Quick select 按钮（EU1 / NAM1 / AU1）选择您的区域，然后粘贴 Application ID 和 API 密钥。

⚠️
重要——请在您的 Application ID 后添加 @ttn。在应用的 Application ID 字段中，将 @ttn 添加到您在步骤 1 中记下的 ID 末尾。没有此后缀，连接将会失败。
因此您的 Application ID 变为
demolokoappid@ttn

点击 Save。当面板顶部的状态指示变为 ● Connected 时，应用已在网络上上线，您追踪器的位置将开始出现在地图上。

🎉 您已连接！

您的 Loko Air 设备现在通过 TTN 将位置流式传输到应用中。从这里，您可以设置地理围栏、查看已存档的轨迹，并下载用于野外的离线地图。
