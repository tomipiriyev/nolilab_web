Loko·设置指南

将 Loko 连接到 LoRaWAN 网络

将您的 Loko Air 追踪器与 The Things Network (TTN) 配对并开始 只需四个简短步骤即可在应用程序中接收实时职位。

~10 分钟 · 适合初学者
自托管您自己的网络服务器？ 如何将 Loko 连接到 ChirpStack → 在自托管 ChirpStack 实例上进行相同的设置 — 使网关上线， 使用 Cayenne LPP 创建设备配置文件，添加您的设备并绘制图表 测量作为仪表。

Loko 接收您的跟踪器位置 LoRaWAN, 远距离, 低功率无线电网络。为了将这些无线电消息桥接到您的手机上，该应用程序 连接到 The Things Network (TTN) — 免费的全球 LoRaWAN community 网络。

设置发生在两个地方：首先您创建一个 应用 在 TTN 上 控制台并注册您的设备，然后将两个凭据粘贴到 Loko 中 应用程序。这里有您需要的一切。

你需要什么

  • ▸
    一个免费的 TTN 帐户注册于 thethingsnetwork.org 如果你没有的话。
  • ▸
    您的 Loko Air 设备详细信息DevEUI / JoinEUI / 键 - 您在注册设备时自行设置。
  • ▸
    已安装 Loko 应用程序在手机上，您将用来跟踪您的设备。
🎯
最后你将得到两个值——一个 应用程序 ID 和一个 API 密钥 — 这是应用程序上线所需的唯一内容。
1

在 TTN 上创建应用程序

登录TTN控制台，打开 应用领域 部分和 单击 + 添加应用程序。为其指定 ID 和名称，然后单击 创建应用程序.

📝
写下您的申请 ID。 您将需要它来使用该应用程序。 在上面的例子中是 demolokoappid。 ID 必须小写并且 以后无法更改。
2

注册您的 Loko Air 设备

在左侧边栏中打开 终端设备，然后单击 注册终端设备.

在注册屏幕上，选择 “手动输入终端设备详细信息”, 然后填写 Loko Air 中的设备详细信息（频率计划、LoRaWAN 版本和配置信息，例如 JoinEUI / DevEUI）。

📡
选择 频率计划 对于您所在的地区（例如 欧洲 863–870 MHz） 并匹配 LoRaWAN版本 到您的 Loko Air。对每个重复此步骤 您拥有的追踪器。
3

创建 API 密钥

返回侧边栏，打开 API 密钥 然后单击 + 添加API密钥。授予其读取应用程序流量的权限，然后保存。

🔑
立即复制 API 密钥 imm。 TTN 仅显示完整密钥 一次，在您创建它之后。将其保存在安全的地方 - 如果您丢失了它 你必须生成一个新的。
✓

可选 — 使用 MQTT Explorer 进行测试

在将凭据放入 Loko 之前，您可以验证它们是否有效 与任何开源 MQTT 客户端 — 例如 MQTT 浏览器。它直接连接到 TTN 的 MQTT 服务器并显示原始上行链路消息，这是一种快速方法 确认一切设置正确。

🔌
使用这些设置： 协议 mqtt://, 主持人 eu1.cloud.thethings.network （匹配您的地区）， 港口 1883。这 用户名 是您的应用程序 ID 与 @ttn 附加（与应用程序相同的规则！），以及 密码 是您的 API 密钥。打 连接 — 如果它连接并且您看到主题 出现，您的凭据就可以使用了。
4

从 Loko 应用程序连接

打开 Loko 应用程序，转到 LoRaWAN (TTN) 工作表，然后输入 您的凭据。选择您所在的地区 快速选择 按钮（EU1 / NAM1 / AU1)，然后粘贴应用程序 ID 和 API 密钥。

⚠️
重要——添加 @ttn 到您的应用程序 ID。 在应用程序的应用程序 ID 字段中，附加 @ttn 到最后 您在步骤 1 中记下的 ID。如果没有此后缀，连接将会失败。
所以你的应用程序ID变成
demolokoappid@ttn

轻敲 节省。当纸张顶部的状态指示灯变为 ● 已连接，该应用程序已在网络上运行并且 您的跟踪器位置将开始到达地图上。

🎉 您已连接！

您的 Loko Air 设备现在通过 TTN 将其位置传输到 应用程序。从这里您可以设置地理围栏、查看存档的曲目并下载 该领域的离线地图。

💬
需要帮助吗？ 如果您在设置过程中遇到任何问题，请检查我们的 常见问题解答部分 或联系我们的支持团队 - 我们随时为您提供帮助 你就连接上了。
