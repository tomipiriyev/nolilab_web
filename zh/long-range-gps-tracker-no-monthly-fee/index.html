远距离 GPS 追踪器，无月费

Loko 将卫星定位与 LoRa 无线电相结合，无需 SIM 卡、蜂窝数据或订阅计划即可提供本地远程跟踪。

大多数远程 GPS 跟踪器通过使用付费网络来实现远程。蜂窝跟踪器使用运营商塔。卫星跟踪器使用卫星消息网络。这两个类别通常都会产生经常性费用。

Loko 则不同。它专为本地远程跟踪而设计。跟踪器接收 GPS 坐标并通过 LoRa 无线电将它们直接发送到您的接收器，从而避免产生每月账单的网络成本。

为什么远程通常按月收费

当跟踪器从任何地方向手机应用程序报告位置时，它需要其他人的网络。这意味着蜂窝运营商、卫星运营商、云服务器和账户基础设施。每月计划支付这些服务的费用。

如果您不需要全球云访问，而是需要跨陆地、步道、工作地点或飞行场进行本地跟踪，则直接无线电设计可以消除经常性成本。

LoRa 如何创建远程本地跟踪

LoRa 专为长无线电链路上的小型低功耗数据包而设计。 GPS 跟踪数据很小：纬度、经度、时间、电池和状态。这使得它非常适合高效的本地跟踪。

实际范围取决于地形、天线高度、视线、建筑物、植被和当地无线电噪声。开阔的地形表现最好。茂密的森林、丘陵和较低的天线位置会缩小覆盖范围。

常问问题

长距离 GPS 跟踪器可以避免月费吗？

是的，当它使用本地无线电链路而不是蜂窝或卫星网络时。 Loko 使用 LoRa 无线电进行本地跟踪。

远距离意味着全球追踪吗？

不会。Loko 适合远距离本地无线电跟踪。全球追踪通常需要蜂窝或卫星服务。

Loko 需要网络吗？

本地 P2P 跟踪否。跟踪器通过 LoRa 无线电将 GPS 坐标发送到接收器。

什么影响 LoRa GPS 范围？

视线、天线位置、地形、植被、建筑物和无线电噪声都会影响实际范围。
