Может ли трекер GPS работать без SIM-карты?

Да. GPS и сотовая связь — это разные системы, а Loko использует GPS плюс LoRa вместо данных на основе SIM-карты.

Трекер GPS может определять свое местоположение без SIM-карты. Спутники GPS передают сигналы позиционирования непосредственно на приемник внутри трекера.

SIM-карта необходима только тогда, когда трекер использует сотовую сеть для отправки этого местоположения куда-то еще. Loko заменяет сотовую связь радиомодемом LoRa.

Распространенное недоразумение

Люди часто говорят GPS, когда имеют в виду всю систему слежения. На самом деле GPS решает только часть местоположения.

Трекеру также необходим метод связи. Большинство брендов выбирают сотовую связь. Loko выбирает радиостанцию ​​LoRa P2P для локального автономного отслеживания.

Как Loko отправляет местоположение без SIM-карты

Loko Air получает свои координаты от спутников GPS, GLONASS и Galileo. Затем он передает эти координаты через LoRa на Loko Ground.

Телефон подключается к Loko Ground через Bluetooth, поэтому для локального рабочего процесса отслеживания не требуется Интернет или оператор сотовой связи.

Когда отслеживание без SIM-карты имеет смысл

Отслеживание без SIM-карты наиболее полезно, когда вы отслеживаете локально в местах с плохой сотовой связью или когда вы хотите избежать повторяющихся затрат на подписку.

Часто задаваемые вопросы

Требуется ли для GPS SIM-карта?

Нет. Для приема GPS не требуется SIM-карта.

Почему большинство трекеров GPS имеют SIM-карты?

Они используют сотовые сети для передачи местоположения в приложение или облачный сервер.

Как Loko избегает SIM-карт?

Loko использует радиомодуль LoRa P2P вместо сотовой передачи данных.

Всегда ли трекер без SIM-карты означает отсутствие подписки?

Не всегда. Некоторые сетевые трекеры без SIM-карты по-прежнему взимают плату за обслуживание. Loko Для отслеживания P2P не требуется подписка на сотовую связь.
