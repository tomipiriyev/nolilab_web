GPS-трекер без интернета

Отслеживайте местоположение там, где у телефонов нет передачи данных, а облачные трекеры перестают обновляться.

Трекер GPS может определять местоположение без интернета, поскольку принимает сигналы непосредственно от навигационных спутников. Различается способ передачи этих координат вам: облачные трекеры используют сотовую передачу данных, а офлайн-трекеры — локальное соединение, например радиосвязь LoRa.

Loko создан для офлайн-отслеживания. Трекер получает координаты со спутников и передаёт их по радиосвязи LoRa на ваш портативный приёмник, поэтому местоположение продолжает обновляться там, где нет Wi-Fi, мобильного интернета и подключения к облаку.

Что означает автономное отслеживание по GPS

Автономное отслеживание по GPS означает, что устройство может определять и передавать местоположение без подключения к интернету. GPS предоставляет координаты. По локальному радиоканалу эти координаты передаются человеку, который ведёт отслеживание.

Это не то же самое, что офлайн-карты. Офлайн-карты позволяют телефону отображать местность без мобильного интернета. Loko добавляет недостающее звено: радиоканал от отслеживаемого объекта к вам.

Где лучше всего использовать трекер GPS без интернета

Автономное отслеживание подходит для лесов, ферм, горных троп, площадок для полётов дронов, загородных участков, строительных площадок, зон поиска и любых мест со слабым сотовым сигналом. В таких местах Bluetooth-метки также перестают работать, поскольку AirTag обновляет местоположение, только когда находящееся поблизости устройство iPhone ретранслирует его; поэтому владельцам собак обычно нужна полноценная GPS- альтернатива AirTag для собак.

Фактическая дальность зависит от рельефа, расположения антенны и прямой видимости. На открытой местности дальность максимальна. Холмы, здания, густая растительность и низкое расположение антенны сокращают её.

Важные ограничения

Loko — не спутниковый мессенджер и сам по себе не передаёт ваше местоположение человеку на другом конце света. Это локальная система отслеживания по радиоканалу большой дальности.

Для экстренной связи далеко за пределами дальности локального радиоканала нужен спутниковый коммуникатор; узнайте, чем локальная радиоальтернатива Garmin inReach отличается. Для локального поиска и отслеживания имущества без интернета лучше подходит Loko.

Частые вопросы

Может ли GPS работать без интернета?

Да. Спутники GPS работают без интернета. Интернет нужен только приложениям и трекерам, которые передают данные через облако.

Может ли Loko показывать местоположение, если на моём телефоне нет сигнала?

Да. Loko Ground принимает данные от трекера по LoRa и подключается к вашему телефону по Bluetooth.

Нужен ли Loko Wi-Fi?

Нет. Для отслеживания P2P с помощью Loko Wi-Fi не требуется.

Это то же самое, что спутниковый трекер?

Нет. Loko — это локальный радиотрекер GPS на базе LoRa, а не устройство спутниковой связи.

Трекер Loko GPS использует GPS и радиосвязь LoRa для локального отслеживания без SIM-карт, интернета и ежемесячной подписки.
