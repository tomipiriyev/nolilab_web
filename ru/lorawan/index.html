Подключение Loko к сети LoRaWAN

Подключите трекеры Loko Air к The Things Network (TTN) и начните получение живых позиций в приложении — за четыре коротких шага.

~10 минут · Подходит для начинающих
Размещаете собственный сетевой сервер самостоятельно? Как подключить Loko к ChirpStack → Та же настройка на локальном экземпляре ChirpStack — подключите шлюз к сети, создайте профиль устройства с помощью Cayenne LPP, добавьте свои устройства и составьте график их измерения как измерительные приборы.

Loko получает координаты вашего трекера LoRaWAN, дальнобойность, маломощная радиосеть. Чтобы передать эти радиосообщения на телефон, приложение соединяется с ХПРОТХ10Х (TTN) — бесплатный глобальный пакет LoRaWAN community. сеть.

Установка происходит в двух местах: сначала вы создаете приложение на TTN консоль и зарегистрируйте свои устройства, затем вставьте два учетных данных в Loko. приложение. Вот все, что вам нужно.

  • ▸

  • ▸

🎯
К концу у вас будет два значения — Идентификатор приложения и API-ключ — это единственное, что нужно приложению для запуска.
1

Создайте приложение на TTN

Войдите в консоль TTN, откройте Приложения раздел и щелкнуть + Добавить приложение. Дайте ему идентификатор и имя, затем нажмите Создать заявку.

📝
Запишите свой идентификатор приложения. Он понадобится вам для приложения. В примере выше это demolokoappid. Идентификатор должен быть в нижнем регистре и не может быть изменено позже.
2

Зарегистрируйте свои устройства Loko Air

В левой боковой панели откройте Конечные устройства, затем нажмите Зарегистрировать конечное устройство.

На экране регистрации выберите «Введите данные конечного устройства вручную», затем заполните данные об устройстве на вашем Loko Air (частотный план, LoRaWAN). версию и информацию об обеспечении, такую как JoinEUI/DevEUI).

📡
Выберите частотный план для вашего региона (напр. Европа 863–870 MHz) и сопоставить Версия LoRaWAN к вашему Loko Air. Повторите этот шаг для каждого трекер, который у вас есть.
3

Создайте ключ API

Вернитесь на боковую панель и откройте Ключи API и нажмите + Добавить ключ API. Предоставьте ему права на чтение трафика приложения, затем сохраните.

🔑
Скопируйте ключ API imm сразу. TTN показывает только полный ключ один раз, сразу после его создания. Сохраните его в безопасном месте — если потеряете. вам придется создать новый.
✓

Необязательно — протестируйте с помощью MQTT Explorer.

Прежде чем вводить учетные данные в Loko, вы можете убедиться, что они работают. с любым MQTT-клиентом с открытым исходным кодом — например MQTT-проводник. Он подключается напрямую к MQTT-сервер TTN и отображает необработанные сообщения восходящей линии связи, что является быстрым способом убедитесь, что все настроено правильно.

🔌
Используйте эти настройки: Протокол mqtt://, Хозяин eu1.cloud.thethings.network (соответствует вашему региону), Порт 1883. Имя пользователя это идентификатор вашего приложения с @ttn добавлено (то же правило, что и для приложения!), и Пароль это ваш ключ API. Ударять Соединять — если он подключается и вы видите темы Похоже, ваши учетные данные в порядке.
4

Подключайтесь из приложения Loko

Откройте приложение Loko, перейдите в ХPROTX0XWAN (TTN) лист и введите ваши учетные данные. Выберите свой регион с помощью Быстрый выбор кнопки (EU1/ NAM1/AU1), затем вставьте идентификатор приложения и ключ API.

⚠️
Важно — добавьте @ttn к вашему идентификатору приложения. В поле "Идентификатор приложения" добавьте @ttn до конца Идентификатор, который вы указали на шаге 1. Без этого суффикса соединение не будет установлено.
Таким образом, ваш идентификатор приложения становится
демолокоаппид@ttn

Кран Сохранять. Когда индикатор состояния в верхней части листа изменится на ● Подключено, приложение доступно в сети и Позиции вашего трекера начнут появляться на карте.
