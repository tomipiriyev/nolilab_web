Подключение Loko к сети LoRaWAN

Свяжите трекеры Loko Air с The Things Network (TTN) и начните получать позиции в реальном времени в приложении — всего за четыре коротких шага.

~10 мин · Для начинающих

Loko получает координаты ваших трекеров по LoRaWAN — радиосети большого радиуса действия с низким энергопотреблением. Чтобы передать эти радиосообщения на ваш телефон, приложение подключается к The Things Network (TTN) — бесплатной глобальной общественной сети LoRaWAN.

Настройка происходит в двух местах: сначала вы создаёте приложение в консоли TTN и регистрируете устройства, затем вставляете два реквизита в приложение Loko. Вот всё, что вам понадобится.

Что вам понадобится

  • ▸
    Бесплатный аккаунт TTNЗарегистрируйтесь на thethingsnetwork.org, если у вас её ещё нет.
  • ▸
    Данные вашего устройства Loko AirDevEUI / JoinEUI / ключи — вы задаёте их сами при регистрации устройства.
  • ▸
    Установленное приложение LokoНа телефоне, с которого вы будете отслеживать устройства.
🎯
В итоге у вас будет два значения — Application ID и API Key — это всё, что нужно приложению для запуска.
1

Создайте приложение в TTN

Войдите в консоль TTN, откройте раздел Applications и нажмите + Add application. Задайте ID и имя, затем нажмите Create application.

📝
Запишите ваш Application ID. Он понадобится для приложения. В примере выше это demolokoappid. ID должен быть в нижнем регистре и не может быть изменён позже.
2

Зарегистрируйте устройства Loko Air

В левой боковой панели откройте End devices, затем нажмите Register end device.

На экране регистрации выберите «Enter end device specifics manually», затем введите данные устройства вашего Loko Air (частотный план, версию LoRaWAN и данные подготовки, такие как JoinEUI / DevEUI).

📡
Выберите частотный план для вашего региона (например, Europe 863–870 MHz) и приведите версию LoRaWAN в соответствие с вашим Loko Air. Повторите этот шаг для каждого вашего трекера.
3

Создайте API-ключ

Вернувшись в боковую панель, откройте API keys и нажмите + Add API key. Предоставьте ему права на чтение трафика приложения и сохраните.

🔑
Скопируйте API-ключ сразу же. TTN показывает полный ключ только один раз — сразу после создания. Сохраните его в надёжном месте: если потеряете, придётся генерировать новый.
✓

Необязательно — проверьте с помощью MQTT Explorer

Прежде чем вводить реквизиты в Loko, вы можете проверить их работу с помощью любого открытого MQTT-клиента — например, MQTT Explorer. Он подключается напрямую к MQTT-серверу TTN и показывает необработанные uplink-сообщения — это быстрый способ убедиться, что всё настроено правильно.

🔌
Используйте следующие настройки: Protocol mqtt://, Host eu1.cloud.thethings.network (для вашего региона), Port 1883. Username — это ваш Application ID с добавленным @ttn (то же правило, что и в приложении!), а Password — ваш API-ключ. Нажмите Connect: если соединение установлено и появляются топики, ваши реквизиты в порядке.
4

Подключитесь из приложения Loko

Откройте приложение Loko, перейдите на вкладку LoRaWAN (TTN) и введите свои реквизиты. Выберите регион кнопками Quick select (EU1 / NAM1 / AU1), затем вставьте Application ID и API-ключ.

⚠️
Важно — добавьте @ttn к вашему Application ID. В поле Application ID приложения добавьте @ttn в конец ID, который вы записали на Шаге 1. Без этого суффикса подключение не удастся.
Итак, ваш Application ID становится
demolokoappid@ttn

Нажмите Save. Когда индикатор состояния вверху вкладки станет ● Connected, приложение подключено к сети, и позиции вашего трекера начнут появляться на карте.

🎉 Вы подключены!

Ваши устройства Loko Air теперь передают свои координаты в приложение через TTN. Отсюда вы можете настроить геозоны, просматривать сохранённые треки и загружать офлайн-карты для использования в поле.
