Обзор

Loko — компактный трекер GPS для дронов. Два подразделения работают вместе: Loko Air (с воздуха) получает GPS и передает по радио LoRa; Loko Заземление (базовая станция) получает данные и передает их в мобильное приложение Loko через Bluetooth.

локо-эйр

Передатчик GPS + LoRa — устанавливается на самолет

  • Литий-ионный аккумулятор 200 mAh
  • 13 г
  • Срок службы батареи до 1 года
  • USB Type-C для зарядки
локо-граунд

Приемник LoRa + реле Bluetooth — остается на земле

  • 18650 Литий-ионный (предоставляется пользователем)
  • Не входит в комплект поставки

Используйте калькулятор срока службы батареи чтобы оценить время работы для вашего интервала пробуждения.

Как это работает

В каждом цикле пробуждения воздушный блок выходит из режима сна, получает координаты GPS, передает координаты наземному блоку, а затем переходит в режим ожидания до следующего цикла. Если спутниковое определение недоступно, передаются последние известные координаты. Журнал маршрута GPS также записывается на внутреннюю флэш-память и может быть загружен через USB.

Часть 1. Настройка Loko Air

Никакого программного обеспечения для установки. Используйте веб-конфигуратор в браузере на базе Chromium.

Firefox и Safari не поддерживаются — нет API Web Serial.

1.1 Открыть конфигуратор

  1. Открыть Хром или Край.
  2. Перейти к nolilab.com/loko-config-tool/
Четыре вкладки: Конфигурация — установка параметров устройства. ГНСС-трассировка — чтение журнала GPS из блока Air, визуализация на карте, экспорт .gpx/.csv. Наземное подразделение — настроить наземный блок. Обновление прошивки — прошить последнюю прошивку.

1.2 Подключиться

  1. Подключите Loko Air к компьютеру через USB-тип-C.
  2. Нажмите Соединять на вкладке Конфигурация.
  3. Предоставьте последовательный доступ браузеру при появлении запроса → выберите правильный порт.
Если порт не отображается, переверните кабель Type-C — ориентация контактов имеет значение.

1.3 Установить параметры → Сохранить изменения

ПараметрОписание
transmit_modeP2P для прямого соединения Воздух-Земля (стандартно). LoRaWAN для интеграции сети и сервера.
frequency868–920 MHz. Должно точно соответствовать наземному блоку.
id1Двухзначный код сопряжения. Должно совпадать как на воздушных, так и наземных подразделениях.
id2Двухзначный идентификатор наземного устройства. Должно соответствовать настройке наземного блока.
wake_up_periodКак часто просыпается воздушный блок. Единицы измерения: с/мин/ч. Короче = быстрее разряжается батарея.
send_multПередача в каждом N-м цикле пробуждения (1 = каждый цикл, 0 = отключить).
save_multЗаписывать трассировку GNSS для каждого N-го цикла пробуждения (0 = отключить регистрацию).
gnss_modeПрофиль движения: Нормальный | Фитнес | Авиация | Воздушный шар | Стационарный. По умолчанию: Нормальный. Используйте авиацию или воздушный шар для дронов.
tx_powerРадиовыход в dBm. Выше = больше дальность, больше расход заряда батареи. По умолчанию: 8 dBm.
p2p_encryptionНеобязательный. 64-значный шестнадцатеричный ключ (32 байта) для AES-256. Должно соответствовать наземному блоку, если он включен.

1.4 Включение

  1. Отключите USB.
  2. Удерживайте кнопку питания, пока не загорится индикатор. мигает красным → агрегат активен.
Горящий красный светодиод = спящий режим между передачами. Нормальное поведение.

Часть 2. Настройка заземления Loko

Loko Ground не имеет встроенной батареи. Перед подключением открутите четыре задних крепления, вставьте 18650 Литий-ионный аккумулятор (не входит в комплект) и соберите заново.

2.1 Открыть конфигуратор → вкладка «Наземный блок»

  1. Перейти к nolilab.com/loko-config-tool/ в Chrome или Edge.
  2. Нажмите кнопку Наземное подразделение вкладка.

2.2 Подключение

  1. Подключите заземление Loko к компьютеру через USB.
  2. Нажмите Соединять → предоставить последовательный доступ → выбрать порт.

2.3 Чтение → обновление → Отправить

  1. Нажмите Читать для загрузки текущих настроек.
  2. Установите приведенные ниже параметры в соответствии с конфигурацией воздушного блока.
  3. Нажмите Отправлять, затем отключите USB.
ПараметрОписание
id22-значный идентификатор. Должен соответствовать идентификатору 2, установленному на блоке Air.
frequency_hzЧастота в Гц (например, 868000000). Должно точно соответствовать воздушному блоку.
p2p_keyТолько если на устройстве Air включено шифрование. Тот же шестнадцатеричный ключ длиной 64 символа.

2.4 Включение и сопряжение

  1. Удерживайте кнопку питания, пока светодиод не погаснет. сплошной синий → готов к сопряжению.
  2. Откройте приложение Loko → предоставьте разрешения Bluetooth → Настройки → выберите «Наземный блок».
  3. Вернитесь на главный экран. Подождите исправления GPS. Местоположение появится на карте.
Поддерживается несколько воздушных единиц. Коснитесь отметки на карте, чтобы просмотреть сведения об устройстве.

Предупреждения

ВОДОНЕПРОНИЦАЕМЫЙ

Не водонепроницаемый. Беречь от жидкостей. Всегда закрывайте порт USB на блоке Air.

ОГОНЬ

Не подвергайте воздействию открытого огня или сильной жары.

ТЕМПЕРАТУРА

Работайте только в диапазоне 0–40 °C.

НАПРЯЖЕНИЕ

Заряжайте только при 5В. Более высокое напряжение разрушит устройство.

РФ

Не заключайте в металл. Держитесь подальше от сильных источников ЭМ.

АНТЕННА

Установите антенну вверх, как можно выше от земли.

БЕЗОПАСНОСТЬ ГЛАЗ

Держите кончик антенны вдали от глаз детей и животных.
