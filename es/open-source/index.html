Qué significa el código abierto para los rastreadores GPS

Hardware y firmware de código abierto significa que los archivos de diseño del dispositivo físico y el código que se ejecuta en él están disponibles públicamente bajo una licencia que permite la inspección, modificación y redistribución.

Para un rastreador GPS específicamente, esto tiene profundas implicaciones:

  • Sin recopilación de datos ocultos: Podrás leer el firmware y verificar que el dispositivo no transmite tu ubicación a nadie excepto a quien tú autorices
  • Sin vulnerabilidades de seguridad de caja negra: Los investigadores de seguridad pueden auditar el código y revelar cualquier vulnerabilidad de manera responsable.
  • Sin dependencia del proveedor: Si nolilab alguna vez dejara de brindar soporte, community podría continuar manteniendo el firmware de forma independiente
  • Personalización: Los desarrolladores pueden modificar el firmware para adaptarlo a casos de uso especializados: diferentes intervalos de actualización, sensores personalizados, protocolos alternativos.
  • Mejoras de Community: Los usuarios con experiencia en ingeniería aportan correcciones de errores, funciones y optimizaciones al proyecto.

La mayoría de fabricantes de seguidores commercial GPS no publican nada. No puede ver qué está haciendo el firmware, si se están almacenando sus datos o cómo se implementa el protocolo de radio. Con Loko no hay secretos.

Esquemas de hardware

Esquemas eléctricos completos tanto para Loko Air como para Loko Ground. Cada componente, cada conexión, cada asignación de pines. Anotado con valores de componentes, números de piezas y comments de fundamentos de diseño.

Archivos de diseño de PCB

Archivos completos de diseño de PCB en formatos abiertos, incluidos archivos Gerber listos para enviar a los servicios de fabricación de PCB. Se incluyen el apilamiento de capas, los vertidos de cobre, los tamaños de vía y la colocación de componentes. Puede solicitar PCB desnudos a cualquier fabricante con estos archivos.

Lista de materiales (BOM)

Lista de materiales completa que enumera cada componente con números de pieza del fabricante, especificaciones y fuentes alternativas sugeridas. Incluye componentes pasivos, circuitos integrados, conectores, el módulo GPS, el módulo de radio LoRa y el microcontrolador.

Código fuente del firmware

Firmware completo escrito en C/C++, que cubre la adquisición de GPS, la programación de transmisión de LoRa, la administración de energía (modos de suspensión), la comunicación Bluetooth comm con la aplicación y la configuración de la constelación GPS (GPS/GLONASS/Galileo).

Código fuente de la aplicación

El código fuente de la aplicación iOS y Android, incluida la representación de mapas sin conexión, el protocolo de comunicación Bluetooth comm y la lógica de análisis de paquetes LoRa.

Por qué el código abierto es importante para el hardware GPS

La cuestión de la confianza es especialmente importante para los dispositivos de seguimiento de ubicación. Un rastreador GPS sabe dónde estás en todo momento, o dónde están tu mascota, tu hijo o tus objetos de valor. Esa es información sensible.

Con los rastreadores propietarios, usted está haciendo una suposición de pura fe: que el fabricante solo le envía sus datos de ubicación, no retiene registros históricos de ubicación en sus servidores, no vende datos de ubicación a terceros y que su firmware no tiene vulnerabilidades de seguridad explotables.

Con Loko, no necesitas fe. El firmware es auditable. El hardware es auditable. El protocolo de comunicación comm está documentado. La arquitectura LoRa P2P (peer-to-peer) significa que los datos de ubicación viajan solo desde Loko Air a Loko Ground; nunca se envían a los servidores de nolilab.

Loko es técnicamente incapaz de enviar su ubicación a los servidores de nolilab — no porque nolilab prometa no hacerlo, sino porque el protocolo de radio no involucra a Internet en ningún paso. El firmware abierto lo demuestra.

Cómo los creadores y desarrolladores utilizan Loko

La naturaleza de código abierto de Loko ha atraído a una comunidad activa de entusiastas y desarrolladores de hardware que han ampliado la plataforma de manera creativa:

  • Intervalos de actualización personalizados: Algunos usuarios modifican el firmware para transmitir cada 1 segundo para recuperación de drones de alta velocidad, o cada 5 minutos para investigaciones de vida silvestre de larga duración para extender aún más la vida útil de la batería.
  • Sensores adicionales: Los desarrolladores han agregado sensores de temperatura, acelerómetros y sensores de presión barométrica al hardware Loko Air para aplicaciones de monitoreo ambiental.
  • Integración LoRaWAN: La radio LoRa se puede reconfigurar para communicate con puertas de enlace LoRaWAN en lugar de un receptor de tierra Loko dedicado, útil para implementaciones de infraestructura fija.
  • Cerramientos personalizados: Community ha aportado diseños de carcasas imprimibles en 3D para aplicaciones de montaje específicas: soportes para drones, carcasas impermeables y accesorios para collares.
  • Integraciones de aplicaciones de terceros: El protocolo Bluetooth documentado permite a los desarrolladores crear sus propias aplicaciones que reciben datos Loko; existen integraciones con Home Assistant, Node-RED y plataformas de mapeo personalizadas.

Si tiene un caso de uso específico que el firmware original Loko no admite, la arquitectura de código abierto significa que puede implementarlo usted mismo sin esperar a que nolilab le dé prioridad.

Rastreador GPS de código abierto: preguntas frecuentes

¿Loko es verdaderamente de código abierto: hardware y firmware?

Sí. Nolilab ha publicado los esquemas completos del hardware, los archivos de diseño de PCB y el código fuente del firmware. Puede inspeccionar cada selección de componentes, rastrear cada decisión del circuito y leer cada línea de código que se ejecuta en el dispositivo. Nada está oculto ni ofuscado.

¿Puedo crear mi propio rastreador Loko GPS a partir de archivos de código abierto?

Sí. Todos los archivos que necesita para fabricar su propio hardware Loko están disponibles públicamente: archivos PCB Gerber, BOM (lista de materiales) y firmware. Si tiene experiencia en la fabricación de PCB y el ensamblaje de SMD, puede construir el rastreador usted mismo. Nolilab también vende unidades probadas y prefabricadas para quienes prefieren un dispositivo listo para usar.

¿Bajo qué licencia se publica el hardware y el firmware Loko?

El hardware y el firmware se publican únicamente para uso personal. No se permite el uso comercial de Comm sin el permiso explícito por escrito de nolilab. Vea la licencia completa en github.com/tomipiriyev/Loko.

¿Puedo modificar el firmware Loko para personalizar los intervalos de actualización o agregar sensores?

Sí. El firmware está escrito en C/C++ y está completamente documentado. Los desarrolladores pueden modificar los intervalos de actualización de GPS, ajustar los parámetros de transmisión de LoRa, agregar soporte para sensores adicionales, cambiar el comportamiento de administración de energía o implementar protocolos personalizados. El firmware abierto es una de las funciones más poderosas de Loko para usuarios técnicos.

¿Por qué nolilab abre el hardware si también lo vende?

Nolilab cree que la transparencia genera confianza. Al publicar públicamente todo el hardware y firmware, los usuarios pueden verificar que Loko hace exactamente lo que dice: sin seguimiento oculto, sin recopilación de datos secretos, sin firmware de caja negra. El community también aporta mejoras al proyecto. Nolilab compite en calidad de fabricación, soporte y experiencia completa del producto, no en mantener los diseños en secreto.
