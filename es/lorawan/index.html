Loko · Guía de configuración

Conexión de Loko a la red LoRaWAN

Empareje sus rastreadores Air Loko con The Things Network (TTN) y comience recibir posiciones en vivo en la aplicación, en cuatro breves pasos.

~10 min · Apto para principiantes
¿Autohospedar su propio servidor de red? Cómo conectar Loko a ChirpStack → La misma configuración en una instancia de ChirpStack autohospedada: poner una puerta de enlace en línea, cree un perfil de dispositivo con Cayenne LPP, agregue sus dispositivos y registre su medidas como calibres.

Loko recibe las posiciones de su rastreador LoRaWAN, un largo alcance, Red de radio de baja potencia. Para conectar esos mensajes de radio a su teléfono, la aplicación se conecta a The Things Network (TTN) — una unidad LoRaWAN community global y gratuita red.

La configuración ocurre en dos lugares: primero creas un solicitud en el TTN consola y registra sus dispositivos, luego pega dos credenciales en el Loko aplicación. Aquí tienes todo lo que necesitas.

lo que necesitarás

  • ▸
    Una cuenta TTN gratuitaRegístrese en thethingsnetwork.org si no tienes uno.
  • ▸
    Detalles de su dispositivo Loko AirLas claves DevEUI / JoinEUI / las configura usted mismo al registrar el dispositivo.
  • ▸
    La aplicación Loko instaladaEn el teléfono que usarás para rastrear tus dispositivos.
🎯
Al final tendrás dos valores: un ID de aplicación y un Clave API – que son las únicas cosas que la aplicación necesita para funcionar.
1

Crear una aplicación en TTN

Inicie sesión en la consola TTN, abra el Aplicaciones sección y haga clic + Agregar aplicación. Dale una identificación y un nombre, luego haz clic Crear aplicación.

📝
Anote su ID de aplicación. Lo necesitarás para la aplicación. En el ejemplo anterior es demolokoappid. El ID debe estar en minúsculas y no se puede cambiar más tarde.
2

Registre sus dispositivos Loko Air

En la barra lateral izquierda abierta Dispositivos finales, luego haga clic Registrar dispositivo final.

En la pantalla de registro, elija "Ingrese los detalles del dispositivo final manualmente", luego complete los detalles del dispositivo desde su Loko Air (plan de frecuencia, LoRaWAN versión y la información de aprovisionamiento como JoinEUI / DevEUI).

📡
Elige el plan de frecuencia para su región (p. ej. Europa 863–870 MHz) y hacer coincidir el Versión LoRaWAN a su Loko Air. Repita este paso para cada rastreador que posee.
3

Crear una clave API

De vuelta en la barra lateral, abre Claves API y haga clic + Agregar clave API. Concédale los derechos para leer el tráfico de la aplicación y luego guárdelo.

🔑
Copie la clave API imm inmediatamente. TTN muestra solo la clave completa una vez, justo después de crearlo. Guárdalo en un lugar seguro, si lo pierdes tendrás que generar uno nuevo.
✓

Opcional: prueba con MQTT Explorer

Antes de colocar las credenciales en Loko, puede verificar que funcionan con cualquier cliente MQTT de código abierto, por ejemplo Explorador MQTT. Se conecta directamente a servidor MQTT de TTN y muestra los mensajes de enlace ascendente sin procesar, lo cual es una forma rápida de Confirme que todo esté configurado correctamente.

🔌
Utilice estas configuraciones: Protocolo mqtt://, Anfitrión eu1.cloud.thethings.network (coincide con tu región), Puerto 1883. El Nombre de usuario es su ID de aplicación con @ttn adjunto (¡la misma regla que la aplicación!), y el Contraseña es tu clave API. Golpear Conectar — si se conecta y ves temas aparecen, sus credenciales están listas para funcionar.
4

Conéctese desde la aplicación Loko

Abra la aplicación Loko, vaya a LoRaWAN (TTN) hoja y escriba sus credenciales. Elige tu región con el selección rápida botones (EU1 / NAM1 / AU1), luego pegue el ID de la aplicación y la clave API.

⚠️
Importante: agregar @ttn a su ID de aplicación. En el campo ID de aplicación de la aplicación, agregue @ttn hasta el final del ID que anotaste en el paso 1. Sin este sufijo, la conexión fallará.
Entonces su ID de aplicación se convierte en
demolokoappid@ttn

Grifo Ahorrar. Cuando el indicador de estado en la parte superior de la hoja cambia a ● Conectado, la aplicación está activa en la red y Las posiciones de tu rastreador comenzarán a llegar al mapa.

🎉 ¡Estás conectado!

Sus dispositivos Loko Air ahora están transmitiendo sus posiciones a través de TTN al aplicación. Desde aquí puedes configurar geocercas, ver tracks archivados y descargar mapas fuera de línea para el campo.
