Conectar Loko a la red LoRaWAN

Empareja tus trackers Loko Air con The Things Network (TTN) y empieza a recibir posiciones en directo en la app, en cuatro breves pasos.

~10 min · Apto para principiantes

Loko recibe las posiciones de tus trackers a través de LoRaWAN, una red de radio de largo alcance y bajo consumo. Para llevar esos mensajes de radio a tu teléfono, la app se conecta a The Things Network (TTN), una red comunitaria LoRaWAN global y gratuita.

La configuración se realiza en dos lugares: primero creas una aplicación en la consola de TTN y registras tus dispositivos, y después pegas dos credenciales en la app Loko. Esto es todo lo que necesitas.

Lo que necesitarás

  • ▸
    Una cuenta gratuita de TTNRegístrate en thethingsnetwork.org si aún no tienes una.
  • ▸
    Los datos de tu dispositivo Loko AirEl DevEUI / JoinEUI / las claves, que defines tú mismo al registrar el dispositivo.
  • ▸
    La app Loko instaladaEn el teléfono que usarás para rastrear tus dispositivos.
🎯
Al terminar tendrás dos valores — un Application ID y una API Key — que es lo único que la app necesita para ponerse en marcha.
1

Crea una aplicación en TTN

Inicia sesión en la consola de TTN, abre la sección Applications y haz clic en + Add application. Asígnale un ID y un nombre, y luego haz clic en Create application.

📝
Anota tu Application ID. Lo necesitarás para la app. En el ejemplo anterior es demolokoappid. El ID debe ir en minúsculas y no se puede cambiar más adelante.
2

Registra tus dispositivos Loko Air

En la barra lateral izquierda abre End devices y luego haz clic en Register end device.

En la pantalla de registro, elige “Enter end device specifics manually” y luego completa los datos del dispositivo de tu Loko Air (plan de frecuencia, versión de LoRaWAN y la información de aprovisionamiento como JoinEUI / DevEUI).

📡
Elige el plan de frecuencia de tu región (p. ej. Europe 863–870 MHz) y haz coincidir la versión de LoRaWAN con tu Loko Air. Repite este paso para cada tracker que tengas.
3

Crea una clave de API

De nuevo en la barra lateral, abre API keys y haz clic en + Add API key. Concédele permisos para leer el tráfico de la aplicación y guárdala.

🔑
Copia la clave de API inmediatamente. TTN muestra la clave completa solo una vez, justo después de crearla. Guárdala en un lugar seguro: si la pierdes, tendrás que generar una nueva.
✓

Opcional: prueba con MQTT Explorer

Antes de introducir las credenciales en Loko, puedes comprobar que funcionan con cualquier cliente MQTT de código abierto, por ejemplo MQTT Explorer. Se conecta directamente al servidor MQTT de TTN y muestra los mensajes de uplink sin procesar, una forma rápida de confirmar que todo está configurado correctamente.

🔌
Usa esta configuración: Protocol mqtt://, Host eu1.cloud.thethings.network (según tu región), Port 1883. El Username es tu Application ID con @ttn añadido (¡la misma regla que en la app!), y la Password es tu clave de API. Pulsa Connect: si conecta y ves aparecer topics, tus credenciales están listas.
4

Conéctate desde la app Loko

Abre la app Loko, ve a la hoja LoRaWAN (TTN) e introduce tus credenciales. Elige tu región con los botones Quick select (EU1 / NAM1 / AU1) y luego pega el Application ID y la clave de API.

⚠️
Importante: añade @ttn a tu Application ID. En el campo Application ID de la app, añade @ttn al final del ID que anotaste en el Paso 1. Sin este sufijo, la conexión fallará.
Así que tu Application ID queda como
demolokoappid@ttn

Toca Save. Cuando el indicador de estado en la parte superior de la hoja cambie a ● Connected, la app estará activa en la red y las posiciones de tu tracker empezarán a aparecer en el mapa.

🎉 ¡Ya estás conectado!

Tus dispositivos Loko Air ya están enviando sus posiciones a la app a través de TTN. Desde aquí puedes configurar geovallas, consultar recorridos archivados y descargar mapas sin conexión para el campo.
