Comment fonctionne Loko

Loko propose deux puissants modes de communication comm pour suivre vos actifs n'importe où et à tout moment.

Mode peer-to-peer (P2P)

Communication directe LoRa comm entre votre tracker Loko et votre smartphone : pas d'Internet, pas d'abonnement, pas de frais mensuels. Parfait pour les aventures en plein air et les endroits éloignés.

Tracker communique avec le récepteur via LoRa P2P (jusqu'à 20km), puis le récepteur se connecte à votre téléphone via Bluetooth

Mode réseau LoRaWAN

Connectez-vous aux réseaux LoRaWAN publics ou privés pour une portée étendue et un suivi mondial. Accédez à l'emplacement de votre tracker depuis n'importe où dans le monde via le cloud.

Loko Air envoie des données à la passerelle LoRaWAN, la passerelle transmet au serveur cloud, votre téléphone accède aux données depuis le cloud
