Connexion du Loko au réseau LoRaWAN

Associez vos trackers Loko Air avec The Things Network (TTN) et démarrez recevoir des positions en direct dans l'application - en quatre étapes courtes.

~10 min · Adapté aux débutants
Auto-héberger votre propre serveur réseau ? Comment connecter Loko à ChirpStack → La même configuration sur une instance ChirpStack auto-hébergée : mettez une passerelle en ligne, créez un profil d'appareil avec Cayenne LPP, ajoutez vos appareils et tracez leur mesures comme jauges.

Loko reçoit les positions de votre tracker sur LoRaWAN, une longue portée, réseau radio de faible puissance. Pour relier ces messages radio à votre téléphone, l'application se connecte à The Things Network (TTN) — une LoRaWAN community gratuite et mondiale réseau.

La configuration s'effectue à deux endroits : vous créez d'abord un application sur le TTN console et enregistrez vos appareils, puis vous collez deux informations d'identification dans le Loko application. Voici tout ce dont vous avez besoin.

Ce dont vous aurez besoin

  • ▸
    Un compte TTN gratuitInscrivez-vous à thethingsnetwork.org si vous n'en avez pas.
  • ▸
    Détails de votre appareil Loko AirLes clés DevEUI / JoinEUI / — vous les définissez vous-même lors de l'enregistrement de l'appareil.
  • ▸
    L'application Loko installéeSur le téléphone que vous utiliserez pour suivre vos appareils.
🎯
À la fin, vous aurez deux valeurs : une ID de l'application et un Clé API - quelles sont les seules choses dont l'application a besoin pour être mise en ligne.
1

Créer une application sur TTN

Connectez-vous à la console TTN, ouvrez le Applications section et cliquez + Ajouter une application. Donnez-lui un identifiant et un nom, puis cliquez sur Créer une candidature.

📝
Notez votre identifiant de candidature. Vous en aurez besoin pour l'application. Dans l'exemple ci-dessus, c'est demolokoappid. L'identifiant doit être en minuscule et ne peut pas être modifié ultérieurement.
2

Enregistrez vos appareils Loko Air

Dans la barre latérale gauche, ouvrez Appareils finaux, puis cliquez sur Enregistrer l'appareil final.

Sur l'écran d'inscription, choisissez « Saisissez manuellement les détails du périphérique final », puis remplissez les détails de l'appareil depuis votre Loko Air (plan de fréquence, LoRaWAN version et les informations d'approvisionnement telles que JoinEUI / DevEUI).

📡
Choisissez le plan de fréquence pour votre région (par ex. Europe 863-870 MHz) et correspondre à Version LoRaWAN à votre Loko Air. Répétez cette étape pour chaque tracker que vous possédez.
3

Créer une clé API

De retour dans la barre latérale, ouvrez Clés API et cliquez + Ajouter une clé API. Accordez-lui les droits de lecture du trafic des applications, puis enregistrez.

🔑
Copiez la clé API imm immédiatement. TTN affiche uniquement la clé complète une fois, juste après l'avoir créé. Enregistrez-le dans un endroit sûr – si vous le perdez vous devrez en générer un nouveau.
✓

Facultatif – tester avec MQTT Explorer

Avant de mettre les informations d'identification dans Loko, vous pouvez vérifier qu'elles fonctionnent avec n'importe quel client MQTT open source - par exemple Explorateur MQTT. Il se connecte directement à Le serveur MQTT de TTN et affiche les messages bruts de liaison montante, ce qui constitue un moyen rapide de confirmez que tout est correctement configuré.

🔌
Utilisez ces paramètres : Protocole mqtt://, Hôte eu1.cloud.thethings.network (correspond à votre région), Port 1883. Le Nom d'utilisateur est votre identifiant d'application avec @ttn ci-joint (même règle que l'application !), et le Mot de passe est votre clé API. Frapper Connecter - s'il se connecte et que vous voyez des sujets apparaît, vos informations d’identification sont prêtes à l’emploi.
4

Connectez-vous depuis l'application Loko

Ouvrez l'application Loko, accédez au LoRaWAN (TTN) feuille et entrez vos informations d'identification. Choisissez votre région avec le Sélection rapide boutons (EU1 / NAM1 / AU1), puis collez l'ID d'application et la clé API.

⚠️
Important - ajouter @ttn à votre identifiant de candidature. Dans le champ ID d'application de l'application, ajoutez @ttn jusqu'à la fin du ID que vous avez noté à l'étape 1. Sans ce suffixe, la connexion échouera.
Ainsi, votre identifiant d'application devient
demolokoappid@ttn

Robinet Sauvegarder. Lorsque l'indicateur d'état en haut de la feuille devient ● Connecté, l'application est en direct sur le réseau et Les positions de votre tracker commenceront à arriver sur la carte.

🎉 Vous êtes connecté !

Vos appareils Loko Air diffusent désormais leurs positions via TTN dans le application. À partir de là, vous pouvez configurer des barrières géographiques, afficher les pistes archivées et télécharger cartes hors ligne pour le terrain.
