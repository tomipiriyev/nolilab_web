インターネットなしの GPS トラッカー

携帯電話にデータ信号がなく、クラウドトラッカーが更新を停止する場所を追跡します。

GPS の場所にはインターネット アクセスは必要ありません。 GPS 衛星は測位信号を世界中にブロードキャストします。インターネットは、多くのトラッカーが位置情報をアプリに中継するためにのみ使用します。

Loko はオフライン トラッキング用に構築されています。トラッカーは衛星位置を受信し、LoRa 無線を介してハンドヘルド受信機に送信するため、Wi-Fi、モバイル データ、クラウド接続がない場所でも位置情報の更新を続けることができます。

オフライン GPS トラッキングの意味

オフライン GPS 追跡とは、デバイスがインターネットに依存せずに位置を計算して共有できることを意味します。 GPS は座標を提供します。ローカル無線リンクは、追跡を行っている人にこれらの座標を伝えます。

これはオフラインマップとは異なります。オフライン マップを使用すると、モバイル データなしで携帯電話に地形を表示できます。 Loko は、追跡されたオブジェクトからユーザーに返される無線リンクという欠落部分を追加します。

インターネットなしで GPS トラッカーを使用するのに最適な場所

オフライン追跡は、森林、農場、山道、ドローン飛行場、田園地帯、建設現場、捜索エリア、および携帯電話サービスが弱いあらゆる場所に適合します。

実際の通信範囲は、地形、アンテナの配置、見通し線によって異なります。開けた地形が最高のパフォーマンスを発揮します。丘、建物、密集した植生、アンテナの位置が低いと通信範囲が狭くなります。

理解すべき限界

Loko は衛星メッセンジャーではなく、それ自体であなたの位置情報を世界中の誰かに送信しません。これは、ローカル長距離無線追跡システムです。

地元の無線通信範囲をはるかに超えた緊急通信には、衛星通信機が最適です。インターネットを使用しないローカル リカバリと資産追跡には、Loko が適しています。

よくある質問

GPS はインターネットなしでも動作しますか?

はい。 GPS サテライトはインターネットなしでも動作します。インターネットは、クラウド データ転送に依存するアプリまたはトラッカーでのみ必要です。

携帯電話に信号がない場合でも、Loko は位置情報を表示できますか?

はい。 Loko Ground は LoRa 経由でトラッカーを受信し、Bluetooth で携帯電話に接続します。

LokoにはWi-Fiが必要ですか?

いいえ、Loko P2P のトラッキングには Wi-Fi は必要ありません。

これは衛星追跡装置と同じですか?

いいえ、Loko はローカル LoRa ラジオ GPS トラッカーであり、衛星メッセージング デバイスではありません。

Loko GPS トラッカーは、GPS と LoRa 無線を使用して、SIM カード、インターネット、月々のサブスクリプションなしでローカル追跡を行います。
