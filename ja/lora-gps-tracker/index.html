技術

LoRaとは何か、なぜGPSトラッカーをより優れたものにするのか？

LoRaはLong Rangeの略です。Semtechが開発した無線変調技術で、チャープ・スペクトラム拡散（CSS）を使用し、Wi-Fi、Bluetooth、Zigbeeでは不可能な距離まで少量のデータを送信します。

重要なのは、LoRaがデータ速度と引き換えに通信距離と障害物透過性を高めていることです。データをゆっくり送信する代わりに、壁や樹木、地形を越えて非常に遠くまで、極めて安定して届けます。数秒から数分ごとに小さな位置情報パケットを送るGPSトラッキングに最適です。

GPSトラッキングでLoRaが他の無線プロトコルより優れている理由

通信距離

キロメートル単位の通信距離

LokoのLoRaリンクは、見通しのよい開けた環境で最大20 kmに達します。Wi-FiやBluetoothなどの近距離通信技術は、異なる通信範囲とデータ速度の要件に合わせて設計されています。

消費電力

超低消費電力

LoRa無線は送信の合間にほとんど電力を消費しません。更新間隔を長くすれば、Lokoは最長1年間稼働します。GPSの測位と送信の頻度を上げると、稼働時間は短くなります。

透過性

障害物を越えて通信

LoRaのサブGHz帯周波数（EUでは868 MHz、米国では915 MHz）は、2.4 GHzのWi-Fiや高周波数帯の携帯通信よりも、植生、建材、緩やかな地形をはるかに通過しやすい特性があります。

独立性

ネットワークインフラ不要

LoRa P2Pは機器同士で直接通信します。トラッキング経路のどの段階でも、携帯基地局、ゲートウェイ、サーバー、インターネット接続は必要ありません。

コスト

運用コストゼロ

LoRaは免許不要のISM無線帯域を使用します。通信料もデータ料金もかからず、通信事業者との契約も不要です。必要な費用はハードウェア代のみです。

信頼性

単一障害点なし

LoRa P2Pリンクを構成するのは、トラッカーと受信機の2つだけです。クラウド、通信事業者のネットワーク、サーバーが存在しないため、それらの停止によって接続が途切れることはありません。

アーキテクチャ

LoRa P2PとLoRaWANの違い — Lokoが採用する方式とその理由

LoRaは物理無線層です。その上には根本的に異なる2つのネットワークアーキテクチャがあり、どちらを選ぶかによってGPSトラッカーの実環境での動作が決まります。

遠隔地での動作 ✅ 常に可能 ⚠️ ゲートウェイが設置されている場所のみ
サブスクリプションの要否 なし 場合による — 必要なことが多い

単一障害点 なし ゲートウェイやサーバーが停止するとトラッキングも停止
最適な用途 屋外、遠隔地、オフグリッド環境でのトラッキング 既存インフラを利用できる固定型IoT環境

Lokoが採用しているのは LoRa P2P. つまり、動物、車両、チームメンバーに装着したトラッカーが、途中のインフラを介さず、携帯型Loko Ground受信機と直接通信します。事前設定もネットワークへの依存もなく、世界中のどこでも数秒でLokoを導入できます。

LoRa P2PとLoRaWANのアーキテクチャを詳しく比較するには、 LoRaWANのページをご覧ください.

技術パラメータ

通信距離とバッテリー駆動時間に影響するLoRa変調設定

LoRaには、通信距離、更新頻度、消費電力の間で直接的なトレードオフを生む、設定可能な変調パラメータがあります。これらを理解することで、用途に合わせてLokoを設定できます。

パラメータ Lokoでの範囲 性能への影響
拡散率（SF） SF7 – SF12 SFが高いほど通信距離は長くなりますが、更新速度が遅くなり、パケット当たりのバッテリー消費量が増えます。SF12で通信距離が最大になります。
帯域幅（BW） 125 kHz / 250 kHz 帯域幅を狭くすると、通信距離と感度が向上します。最大通信距離には125 kHzが標準です。
符号化率（CR） 4/5 – 4/8 CRを高くすると前方誤り訂正の冗長性が増し、データレートと引き換えに、ノイズの多い環境での耐性が向上します。
送信出力 地域の法定上限まで TX出力が高いほど通信距離は長くなりますが、バッテリーの消耗も速くなります。Lokoは地域ごとに最適化されます。

測位精度

GPSの精度：LoRaはどう関係するのか（まったく関係ありません）

よくある誤解ですが、LoRa無線はGPSの測位精度に一切影響しません。この2つのシステムは完全に独立しています。

GPS測位精度 は、すべてLoko Air内のGNSS受信機によって決まります。Lokoは、4つの衛星コンステレーションを同時に利用できます：

  • GPS （米国）— 衛星31基
  • GLONASS （ロシア）— 衛星24基
  • Galileo （EU）— 衛星30基
  • BeiDou （中国）— 衛星35基以上

4つのコンステレーションを同時に利用することで、Lokoは測位開始（初回測位）までの時間が短くなり、精度も向上します。特に、視認できる衛星が限られる峡谷地形や樹冠の密集した場所など、厳しい環境で効果を発揮します。

上空が開けた場所での標準的な測位精度： CEP 2～5メートル （平均誤差半径）。これは一般向けのマルチコンステレーションGNSS機器と同等であり、位置情報の送信に使用する無線技術には左右されません。

LoRaの役割 は送信のみです。GPS座標を受け取り、長距離先の受信機へ誤りなく届けます。LoRaは前方誤り訂正（符号化率パラメータ）を使用し、無線ノイズの多い環境でも位置データを損なわずに届けます。

よくある質問

長距離LoRa GPSトラッカーに関するよくある質問

LoRa GPSトラッカーの通信距離はどのくらいですか？

Lokoは、見通しのよい開けた地形で最大20 kmまで通信できます。都市部の建物、森林、丘、低いアンテナ位置、無線設定により、実際の通信距離は短くなります。詳しくは 無線の見通し距離ガイド で、通信範囲に影響する要因をご確認ください。

LoRa GPSトラッカーとは何ですか？

LoRa GPSトラッカーは、衛星から位置を測定するGNSS受信機と、その位置を長距離へ無線送信するLoRa無線送信機を組み合わせたものです。携帯電話回線を使うGPSトラッカーとは異なり、LoRa GPSトラッカーにはSIMカードやモバイルネットワークが不要です。トラッカーが無線で近くの受信機と直接通信します。

LoRa GPSトラッカーにサブスクリプションは必要ですか？

Lokoにはサブスクリプションが一切必要ありません。携帯電話回線ではなくLoRa無線を使用するため、SIMカード代、データプラン料金、月額料金はかかりません。ハードウェアの購入代金を一度支払えば、期限なく追跡できます。これは、携帯電話回線を使う追跡ソリューションに対するLoRaの大きな利点の一つです。

GPS追跡におけるLoRa P2PとLoRaWANの違いは何ですか？

LoRa P2P（ピアツーピア）は、デバイス同士が直接通信する方式です。途中にインフラを介さず、トラッカーが受信機と直接通信します。LoRaWANはゲートウェイとネットワークサーバーを使用するため、ゲートウェイが設置された地域ではより広い範囲をカバーできますが、そのインフラが必要です。LokoはLoRa P2Pを採用しているため、2台のデバイス以外の準備なしで、どこでも使用できます。詳しい比較については、 LoRaWANのページをご覧ください.

GPS追跡では、LoRaのほうが携帯電話回線より優れていますか？

用途によって異なります。LoRaは、携帯電話回線や端末ごとのデータ通信料を必要としないローカル追跡に適しています。携帯電話回線方式は、追跡対象がネットワーク圏内にあり、近くに受信機がない場合のクラウド経由の遠隔アクセスに適しています。

LoRa GPSトラッカーの測位精度はどのくらいですか？

LokoにおけるGPSの精度は、LoRa無線ではなく、すべてGNSS受信機によって決まります。LokoはGPS、GLONASS、Galileo、BeiDouを同時にサポートし、上空が開けた場所では約2～5メートルCEPの測位精度を実現します。これは、ほかのマルチコンステレーション対応GNSS端末と同等です。LoRa無線は、測位誤差を加えることなくこの位置情報を送信します。

LoRa GPSトラッカーの通信距離に影響する要因は何ですか？

主な要因は、受信機の高度、地形、拡散率、送信出力、アンテナ品質です。見通しのよい開けた地形では、Lokoは最大20 kmまで通信できます。

LoRa GPSトラッカーで複数のデバイスを同時に追跡できますか？

はい。Lokoは、1台のLoko Ground受信機に複数のLoko Airトラッカーを同時接続できます。追跡対象の位置はすべて、同じオフライン地図上にリアルタイムで表示されます。1台のデバイスから動物の群れ、人のチーム、車両群を追跡するのに便利です。

LoRaトラッカーを犬やペットの追跡に使用できますか？

はい。Lokoは、Bluetoothや携帯電話回線の範囲外まで移動する動物向けのLoRa犬用トラッカーまたはLoRaペット用トラッカーとして使用できます。AirTagとは異なり、LoRaトラッカーは最大20 km離れた場所からリアルタイムのGPS位置情報を送信でき、SIMカードも月額料金も不要です。そのため、携帯電話の圏外にいる猟犬、作業犬、放し飼いのペットに適しています。
