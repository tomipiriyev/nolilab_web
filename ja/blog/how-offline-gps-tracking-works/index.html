オフライン GPS トラッキングの仕組み: SIM なし、インターネットなし、月額料金なし

人々が何かを検索するとき、 オフライン GPS トラッカー、それらは通常、携帯電話ネットワーク、SIM カード、または月額料金に依存せずに、何かがどこにあるかを知らせるデバイスを意味します。このガイドでは、その仕組みと、LoRa 無線が最大 20km の範囲でそれを可能にする理由を正確に説明します。

短い答え: GPS自体はすでにオフラインで動作します。 Loko は、LoRa P2P 無線経由でトラッカーから受信機に位置情報を送信することで、チェーンの残りの部分もオフラインに保ちます。技術的な説明ではなく製品ページが必要な場合は、 Loko オフライン GPS トラッカー.

標準の GPS トラッカーの問題

市場に出回っているほとんどの GPS トラッカーは、実際には セルラー GPS トラッカー。 GPS 衛星 (常に機能します) を介して位置を特定しますが、その位置は 4G または LTE セルラー ネットワークを介してクラウド サーバーに送信されます。電話アプリはそのサーバーから位置情報を取得します。

このアーキテクチャには、次の 2 つの避けられない結果があります。

  • セル信号がない = 追跡できない。 森林、山地、農地、僻地では携帯電話の通信範囲が途切れます。トラッカーが真っ暗になります。
  • 購読料。 セルラーデータリンクには、SIM カードと月額データプランが必要です。一般的なコスト: 月額 $5 ～ $15、無期限。

オフライン GPS トラッカーは、セルラー リンクを直接無線接続に置き換えることにより、両方の問題を解決します。

オフライン GPS トラッキングの実際の仕組み

オフライン GPS トラッカーには、内部に 2 つの別個のシステムがあります。

1. GPS測位システム

GPS (およびその同等品である GLONASS、Galileo、BeiDou) は、地球を周回する衛星からタイミング信号を受信することによって機能します。トラッカーは、複数の衛星からの信号が到着するまでにかかる時間を測定することで位置を計算します。これは完全に受動的です。トラッカーは信号を受信するだけで、衛星に送信することはありません。空がはっきりと見える場所であれば、地球上のどこでも機能します。インターネットも SIM もインフラもありません。

2. 無線データリンク

GPS の位置は、受信できる場合にのみ役に立ちます。オフライン トラッカーには、携帯電話ネットワークを経由せずに座標を送信する方法が必要です。ここで無線技術が登場します。

この目的には、さまざまな無線技術が使用されます。

LoRa P2P は、長距離、優れたバッテリー寿命、継続コストゼロ、インフラストラクチャ不要の操作など、ほとんどのユースケースに最適な位置を占めます。

LoRa P2P とは何ですか?なぜオフライン トラッキングが可能になるのですか?

LoRa ロングレンジの略です。これは、無線変調技術、特にチャープ スペクトラム拡散 (CSS) であり、定義された帯域全体で無線周波数を継続的にスイープすることによってデータをエンコードします。このスイープ パターンにより、LoRa 信号はノイズや干渉に対して非常に耐性があり、受信信号がバックグラウンド ノイズ レベルよりもはるかに弱い場合でも信号をデコードできます。

LoRa P2P (ピアツーピア) とは、ゲートウェイ、サーバー、ネットワークなどのインフラストラクチャを使用せずに、トラッカーが受信者と直接通信することを意味します。 Loko GPS トラッカーは、携帯電話に接続されている LokoHUB レシーバーに位置を直接送信します。 LokoHUB は無線信号をデコードし、座標を Loko アプリに転送します。

データ パス全体は次のとおりです。

  1. GPS衛星 → Lokoトラッカー（位置計算）
  2. Loko トラッカー → LokoHUB レシーバー (LoRa 無線経由、最大 20km)
  3. 携帯電話の LokoHUB → Loko アプリ (Bluetooth または USB 経由)

携帯電話の塔はありません。クラウドサーバーはありません。インターネットはありません。位置データがこのプライベート ループから出ることはありません。

LoRa が 1 年間のバッテリーで 20km の航続距離を達成する理由

LoRa の 2 つの主要な利点 (範囲と効率) は同じ源から来ています。チャープ スペクトラム拡散変調は信号エネルギーを広帯域幅に拡散し、非常に低い電力レベルでも非常に堅牢になります。

範囲

一般的な LoRa の送信電力は 14 ～ 22 dBm (25 ～ 160 mW) で、開けた地形では 20km に達します。同様の出力で送信するセルラー無線は、最も近いタワーまで数百メートルをかろうじてカバーします。違いは変調です。LoRa のスペクトラム拡散は、数千のチップにわたって各ビットをエンコードし、従来の受信機では純粋なノイズに見える信号からデータを抽出するのに十分な信号処理ゲインを受信機に与えます。

バッテリー寿命

LoRa の送信は非常に短く、通常はパケットあたり 50 ～ 500 ミリ秒です。送信と送信の間に、無線チップはほぼゼロの電流を消費します (スリープ モード)。 60 秒の更新間隔では、無線がアクティブになる時間は 0.5% 未満です。このデューティ サイクルと 200 mAh バッテリーを組み合わせると、Loko は最大 1 年間動作します。セルラー モデムを継続的に接続すると、同じバッテリーが数時間で消費されます。

実際的な意味: オフライン GPS トラッカーが必要なのは誰ですか?

オフライン GPS トラッカーは、あらゆる状況に適したツールというわけではありません。次のような場合に最適なツールです。

  • 携帯電話の通信範囲外で操作している場合 — 森林、山、農地、人里離れた荒野
  • 継続的なコストをゼロにしたい — サブスクリプションは一切ありません
  • バッテリー寿命は重要 — 数日ではなく、数か月または数年
  • プライバシーの問題 — 追跡データがサードパーティのサーバーを通過することはありません
  • 冗長性が必要です — 携帯電話に信号がないときに機能するバックアップトラッカー

Loko の一般的な使用例: 遠隔地での狩猟犬や作業犬、農機具、ドローン、ボートやカヤック、ハイキングや登山遠征時の個人の安全、携帯電話の通信範囲のない場所に保管されている高価な資産。

オフライン GPS トラッキングの制限事項

オフライン トラッカーで何ができないかを理解することは、オフライン トラッカーで何ができるかを知ることと同じくらい重要です。

  • 範囲は有限です。 理想的な条件では 20km が最大値です。鬱蒼とした森林や山はこれを減少させます。資産が無線範囲を超えて移動すると、信号が失われます。
  • リアルタイムのクラウド アクセスはありません。 トラッカーはサーバーではなく、LokoHUB レシーバーにレポートします。 500km 離れた場所からの位置を見たい場合、LoRa P2P ではそれを提供できません。 (マルチポイントアクセスの場合、ゲートウェイを備えた LoRaWAN により到達範囲を拡張できます。)
  • 視線に依存します。 すべての無線機と同様、LoRa は送信機と受信機の間にクリアなパスがある場合に最高のパフォーマンスを発揮します。地形や建物によって範囲が狭くなります。
