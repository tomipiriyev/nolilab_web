オフグリッド GPS トラッカー

携帯電話の基地局、Wi-Fi、クラウドの範囲を超えた場所の GPS 追跡。

オフグリッド GPS トラッカーは、電話がサービスを失っても機能し続けるはずです。つまり、あらゆる位置情報の更新を GSM、LTE、Wi-Fi、またはクラウド サーバーに依存することはできません。

Loko はオフライン操作を中心に構築されています。衛星から GPS 位置情報を受信し、LoRa 無線によって小さな位置パケットをローカル受信機に送信します。

トラッカーをオフグリッドにする理由

トラッカーは、公共の communication インフラストラクチャに依存せずに、有用な位置データを計算して communicate できる場合、真のオフグリッドとなります。

GPS はグローバル ポジショニングを提供しますが、communication チャネルが難しい部分です。 Loko は、LoRa P2P 無線によるローカル communication の問題を解決します。

オフグリッド追跡が重要な場所

オフグリッド追跡は、農場、トレイル、キャンプ、ドローンフィールド、フィールド調査エリア、建設現場、田舎の土地などで役立ちます。

これは、サブスクリプション トラッカーが高価であり、携帯電話の通信範囲がほとんどまたはまったくないために信頼性が低い場合に特に価値があります。

オフグリッド LoRa では不十分な場合

数千キロメートル離れた場所から世界中の位置情報を更新する必要がある場合は、携帯電話または衛星インフラストラクチャが必要です。

Loko は、人物の追跡が追跡対象の物体と同じ広いエリアにあり、ローカル受信機を使用できる場合に最も効果的です。

よくある質問

オフグリッド GPS トラッカーとは何ですか?

これは、インターネット、Wi-Fi、または携帯電話の通信範囲なしで動作するように設計されたトラッカーです。

Loko には携帯電話サービスが必要ですか?

いいえ、Loko P2P トラッキングでは、セルラー データの代わりに LoRa 無線を使用します。

オフグリッド GPS は衛星メッセージングと同じですか?

いいえ、GPS の測位は衛星ベースですが、communication は LoRa、携帯電話、Wi-Fi、または衛星ネットワークを使用する場合があります。

オフグリッドトラッカーを必要とする人は誰ですか?

ドローンパイロット、農民、ハイカー、野外研究者、遠隔地で資産を追跡するあらゆる人。

Loko GPS トラッカーは、GPS と LoRa 無線を使用して、SIM カード、インターネット、月々のサブスクリプションなしでローカル追跡を行います。
