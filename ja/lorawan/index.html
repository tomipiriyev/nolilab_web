LokoをLoRaWANネットワークに接続する

Loko AirトラッカーをThe Things Network（TTN）とペアリングし、わずか4つのステップでアプリにリアルタイムの位置情報を受信し始めましょう。

約10分 · 初心者向け

Lokoは、長距離・低消費電力の無線ネットワークであるLoRaWANを介してトラッカーの位置情報を受信します。これらの無線メッセージをスマートフォンに橋渡しするため、アプリは無料のグローバルなLoRaWANコミュニティネットワークであるThe Things Network（TTN）に接続します。

設定は2か所で行います。まずTTNコンソールでアプリケーションを作成してデバイスを登録し、次に2つの認証情報をLokoアプリに貼り付けます。必要なものはすべて以下のとおりです。

必要なもの

  • ▸
    無料のTTNアカウントお持ちでない場合はthethingsnetwork.orgで登録してください。
  • ▸
    Loko Airデバイスの詳細DevEUI / JoinEUI / キー — デバイスの登録時に自分で設定します。
  • ▸
    Lokoアプリがインストール済みであることデバイスの追跡に使用するスマートフォンに。
🎯
最後には2つの値 — Application IDとAPI Key — が手に入ります。アプリの稼働に必要なのはこれだけです。
1

TTNでアプリケーションを作成する

TTNコンソールにログインし、Applicationsセクションを開いて+ Add applicationをクリックします。IDと名前を付けてから、Create applicationをクリックします。

📝
Application IDを控えておきましょう。アプリで必要になります。上の例ではdemolokoappidです。IDは小文字でなければならず、後から変更できません。
2

Loko Airデバイスを登録する

左のサイドバーでEnd devicesを開き、Register end deviceをクリックします。

登録画面で「Enter end device specifics manually」を選択し、Loko Airのデバイス情報（周波数プラン、LoRaWANバージョン、JoinEUI / DevEUIなどのプロビジョニング情報）を入力します。

📡
お住まいの地域の周波数プラン（例：Europe 863–870 MHz）を選び、LoRaWANバージョンをLoko Airに合わせます。所有しているトラッカーごとにこの手順を繰り返します。
3

APIキーを作成する

サイドバーに戻り、API keysを開いて+ Add API keyをクリックします。アプリケーションのトラフィックを読み取る権限を付与して保存します。

🔑
APIキーはすぐにコピーしてください。TTNは作成直後に一度だけ完全なキーを表示します。安全な場所に保存してください。紛失した場合は新しく生成し直す必要があります。
✓

オプション — MQTT Explorerでテストする

認証情報をLokoに入力する前に、任意のオープンソースMQTTクライアント（例：MQTT Explorer）で動作を確認できます。TTNのMQTTサーバーに直接接続し、生のアップリンクメッセージを表示するため、すべてが正しく設定されているかをすばやく確認できます。

🔌
次の設定を使用します：Protocol mqtt://、Host eu1.cloud.thethings.network（地域に合わせて）、Port 1883。Usernameは@ttnを末尾に付けたApplication ID（アプリと同じルール）で、PasswordはAPIキーです。Connectを押し、接続してトピックが表示されれば、認証情報は問題ありません。
4

Lokoアプリから接続する

Lokoアプリを開き、LoRaWAN (TTN)シートに移動して認証情報を入力します。Quick selectボタン（EU1 / NAM1 / AU1）で地域を選び、Application IDとAPIキーを貼り付けます。

⚠️
重要 — Application IDに@ttnを追加してください。アプリのApplication IDフィールドで、ステップ 1で控えたIDの末尾に@ttnを追加します。この接尾辞がないと接続に失敗します。
つまりApplication IDは次のようになります
demolokoappid@ttn

Saveをタップします。シート上部のステータスインジケーターが● Connectedに変わると、アプリはネットワーク上で稼働し、トラッカーの位置情報が地図に表示され始めます。

🎉 接続完了！

Loko AirデバイスがTTN経由でアプリに位置情報をストリーミングするようになりました。ここからジオフェンスの設定、保存された軌跡の表示、フィールド用のオフラインマップのダウンロードができます。

💬
