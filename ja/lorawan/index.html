Loko を LoRaWAN ネットワークに接続する

Loko Air トラッカーを The Thing Network (TTN) とペアリングして開始します 4 つの短いステップで、アプリでライブポジションを受信できます。

～10分・初心者向け
独自のネットワークサーバーをセルフホスティングしますか? LokoをChirpStackに接続する方法→ 自己ホスト型 ChirpStack インスタンスでも同じ設定 - ゲートウェイをオンラインにし、 Cayenne LPP でデバイス プロファイルを作成し、デバイスを追加してグラフを作成します ゲージとしての測定。

Loko はトラッカーの位置を受信します LoRaWAN、長距離、 低電力無線ネットワーク。これらの無線メッセージを携帯電話にブリッジするには、アプリ に接続します The Things Network (TTN) — 無料のグローバル LoRaWAN community ネットワーク。

セットアップは 2 つの場所で行われます。まず、 応用 TTNの場合 コンソールにアクセスしてデバイスを登録し、2 つの認証情報を Loko に貼り付けます。 アプリ。必要なものはすべてここにあります。

TTNでアプリケーションを作成する

TTN コンソールにログインし、 アプリケーション セクションと クリック + アプリケーションを追加。 ID と名前を付けて、 をクリックします。 アプリケーションの作成.

📝
アプリケーション ID を書き留めます。 アプリに必要になります。 上の例では、 demolokoappid。 ID は小文字である必要があり、 後で変更することはできません。
2

Loko Air デバイスを登録する

左側のサイドバーを開く エンドデバイスをクリックしてから、 エンドデバイスを登録する.

登録画面で、 「エンドデバイスの詳細を手動で入力します」、 次に、Loko Air からデバイスの詳細を入力します (周波数プラン、LoRaWAN) バージョンとプロビジョニング情報 (JoinEUI / DevEUI など)。

📡
を選択してください 周波数プラン お住まいの地域 (例: ヨーロッパ 863–870 MHz) そして一致します LoRaWANのバージョン Loko Air に。ごとにこの手順を繰り返します あなたが所有するトラッカー。
3

APIキーを作成する

サイドバーに戻り、開きます APIキー そしてクリックしてください + APIキーを追加。アプリケーションのトラフィックを読み取り、保存する権限を付与します。

🔑
API キー imm をコピーします。 TTN ではフルキーのみが表示されます 一度を作成した直後に。紛失した場合は、安全な場所に保管してください 新しいものを生成する必要があります。
✓
