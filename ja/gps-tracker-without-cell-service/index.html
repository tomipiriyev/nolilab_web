携帯電話サービスを使用しない GPS トラッカー

携帯電話の信号が届かない場所で人、ペット、ドローン、機器を追跡します。

GPS トラッカーは、LTE、GSM、またはモバイル データに依存しない位置情報を送信する方法がある場合に限り、携帯電話サービスがなくても機能します。 GPS 衛星が座標を提供します。タワーが消滅すると、ほとんどのトラッカーが失うのは通信リンクです。

Loko は、LoRa 無線機でそれを解決します。トラッカーは衛星から GPS 位置を受信し、小さな位置情報パケットをローカル受信機に直接送信するため、農場、トレイル、ドローンフィールド、田園地帯、遠隔作業現場でも追跡を続けることができます。

ほとんどの GPS トラッカーがセル サービスなしで失敗する理由

多くの「GPS トラッカー」は、実際には GPS とセルラー デバイスを組み合わせたものです。オフラインでも位置を計算できますが、その位置はモバイル ネットワーク経由で送信されます。トラッカーが通信範囲外に出ると、アプリはライブ アップデートの受信を停止します。

これが、人々が森林、渓谷、人里離れた農場、または田舎の大きな敷地内でトラッカーの最後の既知の位置を確認しても、現在の位置を確認できないことがよくある理由です。

携帯電話タワーなしで Loko がどのように追跡するか

Loko は 2 つの異なるテクノロジーを使用しています。 GPS/GNSS は衛星から位置を受信します。 LoRa P2P 無線は、その位置を航空トラッカーから地上受信機にローカルに送信します。受信機は Bluetooth で携帯電話に接続します。

つまり、ローカル追跡には SIM カード、LTE モデム、Wi-Fi、クラウド サーバーは必要ありません。実際の到達距離は、見通し線、アンテナの配置、地形、植生によって異なります。

ノーセルサービス追跡のベストユースケース

田舎の追跡、ハイキング、ペット、GPS アプリに関する Reddit のディスカッションでは、同じニーズが繰り返し示されています。それは、電話アプリや携帯電話のトラッカーが接続できないときに、ライブのローカル位置情報を提供することです。

Loko は、田舎の犬、墜落後のドローン、農機具、トレイルパートナー、フィールドチーム、野生動物プロジェクト、遠隔地周辺の資産の追跡に適しています。

代わりに衛星が必要な場合

近くにローカル受信機がなく、数百キロメートルまたは数千キロメートル離れた場所に位置情報を送信する必要がある場合は、衛星メッセンジャーが適切なカテゴリです。

Loko は、ローカル回復とローカル状況認識に最も優れています。人物追跡はトラッカーと同じ広範囲にあり、LoRa パケットを直接受信できます。

よくある質問

GPS トラッカーは携帯電話サービスなしでも動作しますか?

はい。 GPS は衛星から動作します。トラッカーには、近くの受信機に位置情報を送信するために、LoRa 無線などの非セルラー リンクも必要です。

LokoにはSIMカードが必要ですか?

いいえ、Loko P2P の追跡では、LTE や GSM の代わりに LoRa 無線を使用するため、SIM カードや月々の携帯電話プランはありません。

信号のない田舎で機能するトラッカーは何ですか?

ローカル追跡の場合、LoRa GPS トラッカーはモバイルタワーに依存しないため、携帯電話トラッカーが更新を停止した場合でも機能します。

Loko は衛星トラッカーですか?

いいえ、Loko は位置情報に GPS 衛星を使用し、ローカル通信に LoRa 無線を使用します。これは地球規模の衛星メッセージング デバイスではありません。

Loko GPS トラッカーは、GPS と LoRa 無線を使用して、携帯電話サービス、SIM カード、月々のサブスクリプションなしでローカル追跡を行います。
