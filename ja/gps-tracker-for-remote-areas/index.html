遠隔地用 GPS トラッカー

通常のネットワークが消滅した場所をインフラストラクチャに依存せずに追跡します。

遠隔地追跡には単純な問題があります。多くの GPS トラッカーは、遠隔地に不足している正確なインフラストラクチャに依存しています。

Loko はその依存関係を回避します。トラッカーは衛星位置を受信し、LoRa 無線を使用してローカルに送信するため、通常の GSM およびインターネット カバレッジを超えて動作できます。

インフラストラクチャに依存しない追跡

インフラストラクチャに依存しない追跡とは、トラッカーがローカル位置の更新のためにモバイルタワー、Wi-Fi ルーター、またはクラウドサーバーに依存しないことを意味します。

Loko は、その原則に基づいて設計されています。GPS は測位用、LoRa は通信用、Bluetooth は電話接続用です。

Loko が適した遠隔地

適切な使用例には、田園地帯、森林、山岳地帯、ドローン回収ゾーン、狩猟場、農場、救助訓練場、遠隔地での現場作業などがあります。

開けた地形と見通し線により、LoRa のパフォーマンスが向上します。丘、密林、建物、アンテナが低いと通信範囲が狭くなります。

適切なリモート トラッカーの選択

グローバル SOS およびリモート メッセージングにはサテライト デバイスを選択してください。都市や高速道路の追跡には携帯電話トラッカーを選択してください。 GSM とインターネットが信頼できない場所でローカル追跡が必要な場合は、Loko を選択してください。

よくある質問

GPS 追跡は遠隔地でも機能しますか?

はい、トラッカーに空の可視性があり、地元の携帯電話の塔に依存しない通信方法があれば可能です。

LokoはGSMを使用しますか?

いいえ、Loko はローカル トラッキングに LoRa P2P 無線を使用します。

インフラストラクチャに依存しない追跡とは何を意味しますか?

つまり、ローカル追跡には携帯電話の塔、Wi-Fi、クラウドリレーなどの公衆ネットワークが必要ありません。

Loko は遠隔地の農場やトレイルに適していますか?

はい、展開が実際の LoRa 無線範囲内にある場合は可能です。

Loko GPS トラッカーは、GPS と LoRa 無線を使用して、SIM カード、インターネット、月々のサブスクリプションなしでローカル追跡を行います。
