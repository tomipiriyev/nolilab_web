携帯電話サービスがない状態での GPS トラッカーのハイキング

トレイル、キャンプ、遠隔地屋外ルートのオフラインローカル追跡。

多くのハイキング エリアでは、携帯電話サービスが不安定です。電話機でも GPS を使用できますが、ネットワークがないと位置情報の共有や、移動する人や資産の検索が困難になります。

Loko は、ローカル オフライン トラッキングに GPS と LoRa 無線を使用します。これは、グループ、ガイド、ハンドラー、またはフィールドチームが、携帯電話の通信範囲に依存せずに近くの人、犬、またはギアを追跡したい場合に役立ちます。

Loko がトレイルに適していること

Loko は、実用的な無線範囲内で犬、荷物、自転車、車両、またはグループのメンバーを追跡するのに役立ちます。キャンプ、登山口、探索ゾーン、田舎道などで役立ちます。

このシステムはモバイル データを必要としないため、電話の信号が失われた後も動作し続けることができます。

Loko ではないもの

Loko は、衛星緊急ビーコンや衛星メッセンジャーの代替品ではありません。地球上のどこからでも救助サービスに自動的に通知するわけではありません。

緊急 SOS には、専用の衛星安全装置を使用してください。セル範囲のないローカル追跡の場合、Loko は別の役割を果たします。

屋外での航続距離の予想

開けた尾根と明瞭な地形は、最も強力な無線パフォーマンスを提供します。深い谷、湿った森林、岩、体がブロックされると範囲が狭くなる可能性があります。

ハイキングで使用する場合は、受信機をアンテナの視認性が良い場所に持ち運び、人里離れた地形で信頼する前にセットアップをテストしてください。

よくある質問

GPS は携帯電話サービスなしでハイキング中に使用できますか?

はい。 GPS の受信は携帯電話サービスなしでも機能します。

Loko はインターネットなしで他のハイカーを追跡できますか?

はい、トラッカーと受信機が実際の LoRa 無線範囲内にある場合は可能です。

Loko は SOS デバイスですか?

いいえ、これはローカル GPS 追跡システムであり、緊急衛星メッセンジャーではありません。

Loko には毎月のハイキング プランが必要ですか?

いいえ、Loko は携帯電話の契約を使用しません。

Loko GPS トラッカーは、GPS と LoRa 無線を使用して、SIM カード、インターネット、月々のサブスクリプションなしでローカル追跡を行います。
